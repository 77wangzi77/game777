---

## 1. 公式

```
PREFIX[_chapter]_snake_case
```

- 仅 **ASCII**（字母、数字、下划线）
- 中文只出现在总表 `cn_name` / `note` 等说明列
- Unity 资源文件名 = 总表 `id`；**禁止**中文文件名进工程
- 章号：`01`–`04`（有章语义时写入 id）
- 四层关卡逻辑 id 用 **PascalCase 主题后缀**（见 §3），与 snake 章节叙事 id 并存时各自独立

### 2.1 数值 type 约定（已定）

- `combat_unit` ← N / E / B  
- `skill` ← SK  
- `dmg` ← DMG  
- `encounter` ← ENC  
- 行内配置键 **id = 总表 locked id**，不另起别名  
- locked 行：**只改 value**，不改 id  
- 增补前缀：`CHAR_`、`CFG_`

### 2.2 对话冲突修正（已定）

- 对话节点统一 `DLG_`；**`N_` 仅保留给战斗杂兵**  
- 迁移：`N_host` → `DLG_01_host` 等（见 `redirects.csv`）  
- 程序：工程未大规模落地，迁移成本低；运行时经 `IdRedirect.Resolve`

## 3. 章与四层场景（关卡概念已确认）

| 章 | 用途 |
|----|------|
| 01–04 | 剧情章（对话/过场/任务） |

### 3.1 层号主键（空间）

层号主键统一 **`L01`–`L04`**（不用 `LV_01_mountain` 作主键）：

| 层号 | 空间 | 主题英文 | ENV / PROP / LIT 示例 |
|------|------|----------|------------------------|
| L01 | 高山 | Mountain | `ENV_L01_*`、`PROP_L01_*`、`LIT_L01_*` |
| L02 | 石桥 | Bridge | `ENV_L02_*` … |
| L03 | 岩浆 | Magma | `ENV_L03_*` … |
| L04 | 洞府 | Grotto | `ENV_L04_*` … |

流线：L01高山 → L02石桥 → L03岩浆 → L04洞府。

### 3.2 关卡逻辑 id（四层闭环地牢）

| id | 含义 |
|----|------|
| `LV_L01_Mountain` | 高山层逻辑关 |
| `LV_L02_Bridge` | 石桥层逻辑关 |
| `LV_L03_Magma` | 岩浆层逻辑关 |
| `LV_L04_Grotto` | 洞府层逻辑关 |

公式：`LV_L0x_<Theme>`，Theme ∈ Mountain / Bridge / Magma / Grotto。  
可选短写备注：`LV_L01`…`LV_L04`（总表主键仍用带 Theme 的全 id）。

### 3.3 叙事 VS 与四层并存（勿混）

| id | 角色 | 说明 |
|----|------|------|
| `LV_01_inn` | 章1叙事 VS（驿站夜） | **保留**；与四层地牢无关，**不 deprecate** |
| `ENV_Inn_*` | 驿站环境块（**试玩主线必用**） | 《残简三声》七块：`ENV_Inn_Porch/Hall/Wing/Upper/Yard/Kitchen/Bamboo`；**勿**用 `ENV_L01_*`（四层高山）或 `ENV_01_*`；旧 id 见 redirects |
| `LV_L01_Mountain` 等 | 四层主闭环地牢 | 关卡概念主线空间 |

概念上两套并存：驿站是叙事 VS；四层是主封闭地牢。无 id 碰撞则 **不** 强制 redirects deprecate；仅在总表 `note` 标明角色。

### 3.4 锚点命名（类型前缀 + 实例后缀）

类型前缀（基名）：

| 基名 | 用途 |
|------|------|
| `AN_Teleport` | 传送落点 |
| `AN_Look` | 朝向/引导看点 |
| `AN_Save` | 存档点 |

实例 id 可带层后缀：`AN_Teleport_L01_spawn`、`AN_Look_L01_peak`、`AN_Save_L04_altar`。  
旧 `Anchor_*` → 写入 `redirects.csv`。

ENV / PROP / LIT / M / TEX / AN 并入总表，**owner=场景**（关卡概念对齐模型清单）。

## 4. UI 子类（不替代 UI_ 前缀）

总表 id 仍以 `UI_` 开头；子类写在 `path` 或 `note`：

| 子类标记 | 含义 |
|----------|------|
| ICO_ | 静态图标 |
| IMG_ | 静态图 |
| ANIM_ICO_ | 动画图标 |
| ANIM_IMG_ | 动画图 |

示例：id=`UI_hud_hp`，path=`UI/ICO_hud_hp.png`  
文件名仅 ASCII。

## 5. Unity / 程序约定（已定）

- `Assets` 内资源名与 **locked id 同名**  
- 读表/绑定时：`IdRedirect.Resolve(oldOrNew)` → 新 id  
- 构建与运行时引用：**仅 locked id**（draft 不得进正式包）

---

## 6. 资源总表安全规则

单源：`docs/资源/资源总表.csv`

| 规则 | 说明 |
|------|------|
| status | `draft` \| `locked` \| `deprecated` |
| locked | **禁止改名/删除**；废弃则 status→deprecated，并在 `redirects.csv` 登记 |
| 新增行 | 必须填 `owner` |
| 变更 | 每次在 `changelog.md` **追加一行** |
| 引用 | 数值 / 程序 / 场景构建只引用 **locked** id |
| 数值改值 | locked 行可改配置 value，不可改 id |

配套文件：

- `redirects.csv`：旧 id → 新 id  
- `changelog.md`：变更流水
