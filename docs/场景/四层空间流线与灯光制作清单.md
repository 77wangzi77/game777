## 1. 总流线（VR 舒适）

```
Spawn@L1 崖径落点
  → 亭台引导（冷天窗）
  → 中央石阶 / 天窗升层口 → L2
  → 牌楼入桥 → 桥面灯笼引导 → 门楼
  → 门楼竖井 / 楼梯 → L3
  → 玄武岩平台 + 链桥（岩浆底光）→ 封印门
  → 封印门后竖井 → L4
  → 侧廊汇入大厅 → 祭坛焦点 → 出口/存档锚
```

通用约定（摘自场景规范）：

- 1 unit = 1 m；通道净宽 ≥ 1.2 m；互动高 0.9–1.4 m  
- 传送为主；每层至少 2 个可见 `AN_Teleport`；关键朝向 `AN_Look`  
- 深渊 / 岩浆边：护栏或不可见碰撞墙，禁强迫高速旋转  
- Blockout 先灰模 + 光源色，再贴图

## 4. 制作优先级（场景排期建议）

不设日/周死线；按可戴头显里程碑：

| 里程碑 | 内容 | 验收 |
|--------|------|------|
| S0 Blockout | 四层灰模外壳 + 三连通 + 全 Teleport | 传送走通四层 |
| S1 主建筑 | 每层 1 主建筑（亭/牌楼门楼/封印门/祭坛柱） | 原画体块可读 |
| S2 LIT 四包 | 四套 Volume/灯光预设挂上 | 明暗关系对照原画 |
| S3 P0 道具 | 灯笼/石狮/火盆/竹简堆等 P0 | 引导与焦点成立 |
| S4 舒适抛光 | 护栏、雾坑、热扭曲挂点、坐姿交互位 | 无坠落/眩晕硬伤 |

模型细目以 `四关场景模型清单.md` 为准；本文件管 **流线、锚点、灯光包、层验收**。
