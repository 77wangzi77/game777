## D1（日1）· 开建外廊+堂

**事件 / 产出**
1. 新建 Blender 工程：`VRgame_blender/blockout/LV_01_inn_Blockout.blend`（与四层文件分开）
2. 建 Collection：`ENV_Inn_Porch` / `ENV_Inn_Hall` / `Anchors` / `Colliders`
3. 灰盒：外廊石阶+窄廊+堂门洞；堂内地面+双侧 NPC 站位台（无角色模）
4. 埋点：`AN_Teleport_porch_spawn`、`AN_Look_hall_door`、`AN_Teleport_hall_center`
5. 总表追加上述 ENV/AN 行，owner=场景，status=draft

**验收**：Blender 里从 spawn 视线能看进堂门；单位 1m；通道净宽≥1.2m  
**依赖**：触发区清单已可读（D1 末）  
**交谁**：自检；路径告知程序；埋点名跟触发区表

## D2（日2）· 七区壳 + UI 锚

**事件 / 产出**
1. 补齐 `wing` / `upper` / `yard` / `kitchen` / `bamboo` 灰盒外壳与门洞连通
2. 每区 ≥1 个 `AN_Teleport_*`；关键朝向 `AN_Look_*`
3. 埋 UI 锚：`AN_Look_UI_dialogue`（堂内主对话位）、`AN_Look_UI_menu`（外廊或暂停安全位）、`AN_Look_UI_choice`（抉择位，堂/外廊）
4. 上房门：锁态可见盒子（`PROP_Inn_upper_lock` 占位）

**验收**：七 Collection 齐；传送空物体命名可读；UI 三锚坐标写下表（世界坐标一页）  
**依赖**：UI 确认锚大致朝向；不阻塞可先按堂内眼平 1.5m  
**交谁**：@UI 美术坐标；@程序 预留挂点

## D3（日3）· 碰撞 + FBX 首包

**事件 / 产出**
1. 每区 `PROP_ColliderProxy` 盒：可走地面、护栏、不可坠虚空
2. 门洞净空检查（碰头高≥2.0m）
3. 导出 FBX：`VRgame_blender/export/LV_01_inn_blockout_D3.fbx`（Scale 1，含空物体）
4. 导出说明 md：轴向、单位、AN 列表

**验收**：程序能导入；踩传送点名与空物体一致；无必备精模  
**依赖**：程序工程可进资产（或先放 `blender/export` 等仓）  
**交谁**：@Unity程序
