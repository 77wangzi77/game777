## A. 配置结构（你要填的表）

### A0. 文件约定

| 表名 | 格式 | 用途 |
|------|------|------|
| PlayerLevelStats | CSV/JSON/SO | 玩家每级 HP/MP/SP/攻防暴击 |
| WeaponStats | 同上 | 武器白字、攻速档、击中回 GP |
| DamageFormula | 同上 | 公式 ID + 表达式 + 常数 K |
| SkillNumeric | 同上 | 技能耗蓝耗体、CD、蓄力、倍率、范围 |
| GpRules / MpRules / SpRules | 同上 | 三资源规则 |
| EnemyStats | 同上 | 怪/精英/Boss 血攻防与定位 |
| LevelEconomy | 同上 | 限时、重生次数、胜负奖励 |
| CurveTables | 可选 | 升级曲线、减伤软帽 |

主键一律用已有 ID：`CHAR_*` / `WPN_*` / `SK_*` / `N_*` / `E_*` / `B_*` / `LV_*`。

---

### A1. PlayerLevelStats

| 字段 | 类型 | 说明 |
|------|------|------|
| level | int | 1–10（首章建议封顶 3–5） |
| hp, mp, sp | int | 上限 |
| atk, matk | int | 物理/法术攻击 |
| def, mdef | int | 物防/法防 |
| crit | float | 0–1 |
| critDmg | float | 暴击倍率，如 1.5 |

**成长建议：** HP +12～20/级；ATK +2～3/级；避免单级战力翻倍。

---

### A2. WeaponStats

| 字段 | 说明 |
|------|------|
| weaponId | 如 `WPN_shuangyue_wuhen` |
| atk / matk | 白字 |
| speedTier | low/mid/high → 影响前摇（程序映射） |
| gpOnHit | 命中基础 GP（再随机到规则区间） |

---

### A3. DamageFormula

统一入口（与战斗系统一致）：

```
final = expr(...)
hp' = clamp(hp - final, 0, hpMax)
```

| formulaId | 用途 | 表达式草案 |
|-----------|------|------------|
| DMG_melee_light | 斩击 | `(atk+weaponAtk)*mul*(1-def/(def+K_def))` |
| DMG_line | 直线技 | 物法混合减 mdef |
| DMG_sin | Sin 技 | 偏 matk |
| DMG_parabola | 抛物线 | 偏 matk + 落地 AOE 可二次表 |
| DMG_ult_slash | 天灰无影 | 含 `chargeScale` |

**K_def / K_mdef 默认 50**（减伤软帽）。改 K 前先打模拟器。

暴击：`if rand<crit: final *= critDmg`。

---

### A4. SkillNumeric（与技能配置结构 costs/cd 同源）

| 字段 | 说明 |
|------|------|
| skillId | 与 `SkillConfig.skillId` 同一 |
| mp, sp, gp | 消耗；不足不能放 |
| cd | 秒 |
| chargeTime | 0 或 3（蓄力标准） |
| mul | 单值或斩击三段数组 |
| formulaId | 指向 A3 |
| aoeRadius / impactRadius | 范围技 |

**导入校验：** JSON 技能表与本表 skillId 必须对齐，缺行报错。

---

### A5. GP / MP / SP 规则块

| 块 | 关键字段 |
|----|----------|
| GpRules | max100；命中 +8～12；完美格挡 +15；断蓄 -30；蓄力 0.6～3s → 伤害尺 1.0～1.35 |
| MpRules | 不足禁技；战外回复；战中默认 0（防无脑放） |
| SpRules | 跑耗/秒、滚定额；0 则 **仅行走**；闲置回复 |

---

### A6. EnemyStats（预算表）

| 字段 | 说明 |
|------|------|
| id | N_/E_/B_ |
| level | 建议对抗等级 |
| hp, atk, matk, def, mdef | |
| role | trash / elite / boss |
| ttkSec | **设计目标** 被标准剑客满配击杀秒数 |

程序可不读 ttkSec；这是数值自测锚点。

---

### A7. LevelEconomy

| 字段 | 说明 |
|------|------|
| levelId | |
| timeLimitSec | 0=不限时 |
| respawnCount | 与关卡 `allowRespawn` 联动 |
| winRewardSilver / loseRewardSilver | 结算碎银 |
| expWin / expLose | 可选 |

失败退出（F_QUIT）走 lose 奖励（可为 0）。

## B. 数值平衡设计

### B1. 目标手感（锚）

| 场景 | 目标 |
|------|------|
| 杂兵 TTK | 3–6 秒 |
| 精英 TTK | 20–40 秒 |
| Boss TTK | 1.5–3.5 分钟 |
| 同等级杂兵 | 不可 2 刀秒杀玩家 |
| MP 池 | 无回复时约 4–6 次主动技 |
| SP 池 | 约 2–3 次滚 + 短加速后进入只走 |
| 天灰无影 | 清一小簇杂兵或打掉 Boss 一节血（约 15–25% 单阶段） |

### B2. 平衡闭环（你怎么调）

```
定 TTK 锚 → 反推怪 HP 与玩家 DPS
 → 调技能 mul / CD / MP
 → 打 ENC_tut / ENC_yard / Boss 时间轴
 → 看死亡次数与蓝耗
 → 再改 PlayerLevel 或 K_def
```

**一次只动一类表**（先 mul，再 HP，再 CD），并记变更日志。

### B3. DPS 粗算（剑客 Lv1）

- 武器+ATK ≈ 12+14=26 白戳，斩击均倍 ≈ 1.15 → 单刀期望约 20（未计暴击减伤）  
- 攻速按 1.2 刀/秒 → 对 0 防 DPS≈24  
- 刀手 HP40 → TTK≈1.7s 偏快 → **示例表已把刀手放 40、防 2，实机若偏快则升怪 HP 或降 mul**  

请用表示例做第一轮实机后再锁 v1。

### B4. Boss 节拍

| Boss | HP 草案 | 阶段 | 单阶段期望时长 |
|------|---------|------|----------------|
| B_host | 180 | 50% | 各 ~30–40s |
| B_bamboo | 280 | 60/25 | 合计 ~2–2.5min |
| B_shrine | 360 | 三阶段 | ~2.5–3min |
| B_mirror | 420 | 66/33 | ~3min+ |

转阶段无敌时间 **不计入** 有效 DPS。

### B5. 资源三角

| 资源 | 压力来源 | 过强信号 | 过弱信号 |
|------|----------|----------|----------|
| HP | 挨打、限时失误 | 从不喝药/从不死 | 教程关反复死 |
| MP | 锁定技/直线/Sin/抛物线/天灰 | 蓝永远满 | 只能普攻 |
| SP | 跑滚 | 永远可滚 | 只会走、无法教闪避 |
| GP | 要普攻叠 | 开场就能大招 | 大招整关放不出 |

### B6. 关卡胜负与数值

- 限时关：任务长度 + 战斗 TTK 总和应 **&lt; timeLimitSec × 0.7**（留探索/对话）  
- 重生：每次重生可清空 SP/MP 部分回复（待定）；次数耗尽 → 失败结算  
- 退出失败：无奖励或仅统计，不发胜奖  

### B7. 版本与权限

- 表示例为 **v0 草案**，数值策划可直接改 JSON/CSV  
- 改公式 K 或暴击需同步战斗程序  
- 与策划技能 ID 冲突时以 **技能配置结构** 的 ID 为准，数值只填量
