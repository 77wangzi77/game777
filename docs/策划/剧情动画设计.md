# 剧情动画设计（秦朝山海经 · 勇士斩妖）

> 形式：PCVR 可坐姿观看的过场 + 半互动演出（可跳过非 ★ 段）  
> 工具建议：Timeline / Cinemachine（VR 慎用大幅度推镜）+ 动画状态机  
> 原则：**少甩头、多世界演出**；重要信息可进见闻录

---

## 1. 动画类型

| 类型 | 代号 | 时长预算 | 玩家控制 | 用途 |
|------|------|----------|----------|------|
| 全过场 | CS | 20–45s | 不可动，可跳过(非★) | 章序/揭晓 |
| 半互动演出 | SC | 10–25s | 可微转头/坐姿 | 对话中兽现 |
| 战斗引入 | BI | 5–12s | 锁移动，可格挡预备 | Boss/精英入场 |
| 击杀演出 | KO | 2–5s | 短锁 | 点名除魔 |
| 结算演出 | ST | 8–15s | UI 可点 | 胜负 |

★ = 不可跳过关键句（与对话节点一致）。

---

## 2. VR 镜头规范

| 项 | 规则 |
|----|------|
| 机位 | 默认玩家头位；过场用「世界演员表演」而非抢镜头 |
| 禁止 | 强制长时间旋转、高速推拉、落地甩头 |
| 允许 | 轻微曝光/灰雾、目标高亮、兽从视野边缘入画 |
| 坐姿 | 全部 CS/SC 支持坐姿完成 |
| 字幕 | 世界空间或舒适 HUD；兽名首次出现加注「山海经·××」 |

## 5. 动画状态与程序接口

| 事件 | 方向 | 说明 |
|------|------|------|
| `Cutscene.Play(id)` | 关卡→动画 | 播指定 ID |
| `Cutscene.Ended(id)` | 动画→关卡 | 续任务/刷怪 |
| `Cutscene.Skip()` | 输入 | 非★可跳；写设置 |
| `BossIntro.Play` | 战斗 | BI 结束进可伤帧 |

Timeline 绑定：禁用玩家移动层；保留 HMD 旋转（限角速度）。

---

## 7. 验收

1. 出生后必能看到 intro，坐姿可看完  
2. 至少 1 次点名兽以「影/声/皮」入画（猙或九尾）  
3. BI 结束后伤害盒/AI 正确激活  
4. 无强制甩头；跳过不破任务 flag  
5. 胜负结算动画可进可出
