## 1. 基础攻击（近战武器盒）

### 1.1 检测模型

| 项 | 规则 |
|----|------|
| 中心 | **以角色为中心**（角色根/胸口锚点） |
| 形状 | **手持武器为矩形包裹（OBB / 盒状碰撞）** |
| 跟随 | 盒体随武器骨骼（刃段）变换；出招帧激活 |
| 目标 | 武器盒 **Overlap / Sweep** 到的、带「可受伤」层的物体 |
| 结算 | 命中合法目标 → 进入 **伤害计算**（见 §3） |
| 同段去重 | 同一招式同一目标只结算 1 次（除非多段命中帧） |

### 1.2 攻击检测锁定规则

| 规则 | 说明 |
|------|------|
| 无锁定普攻 | 基础斩击：盒内谁碰到算谁；可多目标（待填是否劈中多人） |
| **单体锁定技能** | 释放前需锁定目标；锁定期间目标标记 |
| 锁定强度 | **无抵消、不可挡断**（技能飞行/生效中不被驱散、不被格挡取消） |
| 消耗 | 此类技能 **消耗 MP（魔法值）**；MP 不足不可放 |
| 丢失目标 | 目标死亡/出界：技能仍沿锁定点或提前结束（待填二选一） |

### 1.3 区域技能（以自己为中心）

| 项 | 规则 |
|----|------|
| 形状 | **以自己为中心的园区/圆形（或扇形）范围** |
| 结算 | 范围内所有合法目标 **分别计算伤害数值** |
| 移动 | **移动时与正常技能释放一致**（不因走动改判定逻辑；是否可边走边放见技能表） |

## 2. 三维资源：HP / MP / SP

| 资源 | 含义 | 关键阈值 | 归零后果 |
|------|------|----------|----------|
| **HP** | 生命 | — | **HP ≤ 0 → 角色 & NPC 死亡**，播放死亡状态（§8） |
| **MP** | 魔法 | 技能表 `mpCost` | **MP ≤ 0 或不满足该技能消耗 → 无法释放任何耗 MP 技能** |
| **SP** | 体力 | 移动加速/滚动等 `spCost` | **SP ≤ 0 或不满足体力消耗时：玩家移动紧为行走状态**（禁止跑/滚等耗 SP 机动） |

### 2.1 回复（草案，待填精确曲线）

| 资源 | 战斗中 | 脱战 |
|------|--------|------|
| HP | 默认不自动；药/技能 | 缓慢或石灯 |
| MP | 可选慢回 / 击中回蓝 | 较快回 |
| SP | 停止耗 SP 动作后回 | 快速回 |

### 2.2 与剑客文档对齐

- 天灰无影等若走 **GP 蓄力槽**，与 MP 并列：耗 MP 的技能走 MP，蓄力终极可「MP+GP」双条件（待你定）  
- SP 对应行走/加速/滚动限制，与角色操作系统一致

## 3. 伤害计算（统一入口）

```
最终伤害 = f(攻击方攻击力, 技能倍率, 暴击, 防御减伤, 易伤/抗性)
HP' = clamp(HP - 最终伤害, 0, HPMax)
```

| 步骤 | 内容 |
|------|------|
| 1 命中判定 | 武器盒 / 技能区域 / 弹道命中 |
| 2 标签过滤 | 友军、无敌、已死亡跳过 |
| 3 数值 | 读技能 `damageFormula` |
| 4 受击 | 目标播放受击；刷新 HP UI（§7） |
| 5 死亡检查 | HP≤0 → 死亡流程 |

**受击范围：** 被击中的物体播放 **受击动画**，并按上式做 **HP 伤害数值** 结算。

## 4. 技能设计

### 4.1 技能形态一览

| 形态 | 判定 | 伤害 | 备注 |
|------|------|------|------|
| **直线技能** | 沿朝向射线/长条盒向前 | 路径上目标结算 | 宽度、长度、穿透待填 |
| **Sin 技能** | 沿正弦曲线轨迹（左右摆）前进 | 轨迹采样点碰撞或带状 | 振幅、波长、速度待填 |
| **个体中心范围** | 以施法者（或目标）为圆心/园区 | 范围内 AOE | 同 §1.3 |
| **抛物线技能** | **锁定目标后**，特效沿抛物线飞向目标点 | 到达（或爆炸半径）结算 | 弧高、飞行时间待填 |
| **基础近战斩击** | 武器矩形盒 | 见 §1.1 | 可不耗 MP |

### 4.2 技能冷却（CD）

| 规则 | 说明 |
|------|------|
| 条件不足 | 不满足 MP/SP/锁定/等条件时 **不可进入释放** |
| CD 计时 | 成功释放后进入 CD；**CD ≤ 0 时冷却结束可再放** |
| UI | CD 遮罩/转圈（待 UI） |
| 打断 | 若释放被硬打断：是否返还 CD/MP → **待填**（建议：前摇打断返还，后摇不返还） |

### 4.3 技能蓄力释放

| 项 | 规则（按你口述） |
|----|------------------|
| 输入 | **蓄力键持续按住 3 秒** 后释放技能 |
| 未满 3 秒 | 松开则取消或弱化版（待填；默认取消不耗完整 CD） |
| 满 3 秒 | 释放；按技能类型做 **目标锁定** 或 **范围伤害** 方案 |
| 检测 | 释放瞬间重检：MP、CD、锁定有效性、范围列表 |
| 示例对接 | 「天灰无影」可定为 3s 蓄力 + GP/MP 条件（与角色文档对齐时改一处） |

### 4.4 单体锁定技能（再强调）

- 锁定后：**无抵消、不可挡断**  
- 必耗 **MP**  
- 可用于直线/抛物线等需目标的形态  

### 4.5 技能配置表模板（给程序）

| 字段 | 类型 | 说明 |
|------|------|------|
| skillId | string | |
| shape | enum | meleeBox / line / sin / selfAoE / parabola |
| lockType | enum | none / single / noneButAoE |
| unbreakable | bool | 单体锁定技建议 true |
| mpCost | int | |
| spCost | int | 默认 0 |
| cd | float | 秒 |
| chargeTime | float | 蓄力秒，0=非蓄力；口述标准=3 |
| damageFormula | string/id | |
| moveRule | enum | allowMoveSameAsNormal / rootSelf |

## 5. 移动与技能

| 规则 | 说明 |
|------|------|
| 一致性 | **移动时和正常技能释放一致**（判定、消耗、CD 规则不另起一套） |
| SP 门闸 | SP 不足：仅行走；不影响「已放出」的技能飞行物（待填） |
| 蓄力中移动 | 默认允许慢走；跑/滚取消蓄力（建议） |

## 6. 死亡判定（角色 & NPC）

| 项 | 规则 |
|----|------|
| 条件 | **HP ≤ 0** |
| 表现 | 进入死亡状态：死亡动画 + 特效（§8） |
| 逻辑 | 关碰撞受伤、清仇恨、派发击杀/任务事件 |
| 玩家 | 接石灯重生等（见角色系统） |
| NPC/Boss | 接掉落、flag、阶段机 |

## 7. UI 动态显示

### 7.1 HP-UI

| 项 | 规则 |
|----|------|
| 数值 | 显示当前 HP / Max（或仅当前，待填） |
| 动态血条 | 受伤后：**数值立刻或短延迟更新** + **血条动态减少动画** |
| 建议 | 即时层（红）+ 缓随层（灰拖尾）表现伤害量 |

### 7.2 MP-UI

| 项 | 规则 |
|----|------|
| 数值 | 当前 MP 数值 |
| 动态条 | **释放技能后** 显示消耗，**MP 条动态减少** |
| 不足 | 技能按钮置灰/闪提示 |

### 7.3 SP-UI

| 项 | 规则 |
|----|------|
| 数值 | 当前 SP 数值 |
| 动态条 | **释放耗 SP 的技能或跑/滚后** 动态减少 |
| 耗尽 | 提示进入「仅行走」；加速键无效 |

### 7.4 VR 摆放（建议）

- 腕托或腰牌三短条：HP/MP/SP，避免挡视野中央  
- 舒适度：减少频繁闪红全屏

## 8. 受击 / 死亡表现

| 类型 | 规则 |
|------|------|
| 受击 | 被击中物体播 **受击动画**；可附受击特效 |
| 死亡 | HP≤0 播 **死亡动画 + 死亡特效** |
| 资源来源 | **参考美术具体设计的角色方案与动作动画设计**（本策划只定触发点与时长预算） |
| 时长预算 | 受击硬直 0.2–0.5s；死亡演出 1.5–3s 可跳过（玩家侧慎用跳过） |

## 9. 流程串（程序）

```
输入攻击/技能
 → 检查 CD / MP / SP / 蓄力时间 / 锁定
 → 播动作与特效
 → 激活武器盒 或 生成直线/Sin/AOE/抛物线判定体
 → 收集目标 → 伤害计算 → 改 HP
 → 刷新 HP/MP/SP UI 动态条
 → 若 HP≤0 → 死亡状态
```

## 10. 验收清单

1. 武器矩形盒能稳定打中碰撞体并扣 HP  
2. 单体锁定技：无 MP 放不出；锁定后按「不可挡断」结算  
3. 自身范围技：圈内多目标各自掉血  
4. 直线 / Sin / 抛物线 三种弹道至少各 1 个测试技可跑通  
5. 蓄力键按满 3 秒才释放；中途松开符合取消规则  
6. HP≤0 播死亡；MP 不足禁技；SP 不足仅行走  
7. HP/MP/SP 三条 UI 均有数值 + 动态缩减
