# 验收标准（复杂叙事版 VS）

## 产品验收（戴上头显）

| # | 标准 | 通过条件 |
|---|------|----------|
| 1 | 时长 | 生手 15–25 分钟可通关；熟手可更快 |
| 2 | 舒适 | 默认传送；无强制高速旋转；过场可坐姿 |
| 3 | 主线不断 | 不看攻略可完成 QM0→QM5；允许错过 expose |
| 4 | **复杂可达** | 同一存档周目内，逻辑上存在 unlock `expose` 的路径（QA 用检查表跑通） |
| 5 | 信息差可感 | 至少 1 组矛盾证据在 UI/对话中可对照（时辰或物证） |
| 6 | 三分支可感 | chase / guard / expose 三过场文案或镜头不同；`none` 可作超时兜底 |
| 7 | 人物线非空 | 哑仆或旅客至少一条深谈改变可选选项 |
| 8 | 断点 | 离关后可从存档续；flag 可读 |

## 叙事 QA 检查表（必跑）

1. 只听掌柜 + 开匣 → 只能 chase/guard，**不能** expose  
2. 掌柜 + 旅客矛盾 + 残页/伪匣 + 字条 → **能** expose  
3. 超时不选 → `none` 过场  
4. 旅客反水后掌柜试探台词变化  

## 文档 / 管线

| # | 标准 |
|---|------|
| D1 | 任务网与对话条件变量表一致 |
| D2 | 场景 7 点可被场景岗拆任务 |

## 不验收

- 战斗连招、多周目成就墙、最终美术
- 全头显矩阵（先一款主力 PCVR）
