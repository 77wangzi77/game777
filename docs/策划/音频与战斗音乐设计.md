# 音频与战斗音乐设计（秦朝山海经 · 勇士斩妖）

> 平台：PCVR · Unity · 古剑气质（忌赛博霓虹）  
> 对接：`剧情动画设计.md`、`战斗系统.md`、`战斗技能配置结构.md`、`NPC技能与动作动画.md`、`命名规范.md`  
> 状态：草案 · 种子 id 总表均为 **draft** · 待用户拍板升 locked

---

## 1. 目标与 VR 舒适

| 项 | 约定 |
|----|------|
| 气质 | 秦驿夜鼓、山海异兽低鸣、古剑弦乐；斩妖点名时短促锣/磬，忌电子舞/赛博合成 |
| 峰值 | **禁止突然贴耳大音**；战斗爆发相对探索 ≤ **+6 dB**；Boss 入场相对杂兵战 ≤ **+3 dB** |
| 空间 | 世界 SFX 用 **3D Spatial**（近距衰减清晰）；BGM/VO/UI 默认 **2D Stereo** |
| 听感保护 | 高音尖啸限幅；连续受击命中声做 **同音快速叠消**（短时同 clip 最多 3 层） |
| Ducking | VO 出现时 BGM −6〜−9 dB；战斗进入时 Amb 压低；结算 VO 压战斗 SFX |
| HMD | 默认跟随头；关键旁白可短时「世界锚点」发声（驿门/祭坛），避免强制甩头找声源 |

## 2. AudioMixer 总线

| Bus | 用途 | 建议默认 dB | Snapshot 要点 |
|-----|------|-------------|---------------|
| Master | 总音量 | 0 | 设置页滑条 |
| BGM | 探索/战斗/过场床/刺音 | −6 | Explore / Combat / Boss / Cutscene / Result |
| SFX_Combat | 武器、命中、敌预警、技能 | −3 | Combat 抬、Cutscene 压 |
| SFX_UI | 菜单、HUD、结算点选 | −4 | 始终可闻，不随战斗巨幅抬 |
| SFX_World | 机关、门、拾取、传送 | −5 | 探索清晰 |
| VO | 旁白、点名兽名、NPC 短句 | −2 | 优先 duck 其它 |
| Amb | 层氛围床、驿站夜 | −8 | Combat 再 −4〜−6 |

建议 Snapshot 名：`Snap_Explore` / `Snap_Combat` / `Snap_Boss` / `Snap_Cutscene` / `Snap_Result`。

## 4. 层切换规则

| 切换 | 规则 |
|------|------|
| 探索 → 战斗 | Crossfade **1.5–2.5s**；`Snap_Combat`；Amb duck |
| 战斗 → 探索 | Crossfade **2.0–2.5s**；清场/脱战触发；残留 stinger 不叠 BGM |
| 杂兵 → 精英 | 同 Combat bus 内换床，crossfade **1.0–1.5s** |
| Boss BI | `BI_*` 开始切 `Snap_Boss`；**intro 段与 Timeline 对齐**（`BGM_boss_*` 前 5–12s）；`BossIntro` 可伤帧后进 loop |
| KO | 短压 BGM −3 dB；可叠 KO 锣/散灰 SFX；不换整曲 |
| ST 胜/负 | 战斗床 fadeout ≤1.5s → `BGM_stinger_win/lose` → UI |
| CS/SC | `Snap_Cutscene`；世界 SFX 保留关键点（门、啼） |

程序接口建议：`AudioDirector.SetState(Explore|Combat|Boss|Cutscene|Result)` + `PlayBgm(id, fadeSec)`。

## 7. VO

| 类型 | id 模式 | 规则 |
|------|---------|------|
| 旁白 | `VO_narr_01_*` | 与字幕时间轴对齐；★句不可跳过段必须有 VO 或可关 VO 留字幕 |
| 兽名首次点名 | `VO_beast_name_<key>` | 字幕「山海经·××」；音量优先 duck BGM |
| NPC 短句 | `VO_dlg_01_*` | 可选；无 VO 时仅字幕 |
| KO 点名 | 可复用兽名 VO 短尾 | 与 `KO_*` 同步 |

设置：主音量 / BGM / SFX / VO 分滑条；「字幕同步 VO」默认开。

## 8. Unity 落地

```
Assets/_Project/Audio/
  Mixer/VRgame_AudioMixer.mixer
  BGM/          # Addressables 组 Audio_BGM
  SFX/Combat/
  SFX/UI/
  SFX/World/
  Amb/
  VO/
```

| 项 | 约定 |
|----|------|
| 资源名 | 与总表 **locked id** 同名 |
| 加载 | Addressables；BGM/Amb 可预载层包 |
| 池 | 战斗命中 SFX 对象池；同帧限实例 |
| 3D | Combat/World 用 Spatial Blend→1；Max Distance 按招式（扑杀 ~12m，斧 ~18m） |
| Timeline | CS/BI 轨绑 `BGM_*` / `SND_*` / `VO_*`；BI 结束事件通知 AudioDirector 进 loop |

## 10. 验收

1. 探索↔战斗 crossfade 在 1.5–2.5s，无爆破贴耳  
2. Boss BI 与 `BGM_boss_*` intro 对齐；可伤帧后进 loop  
3. 鬼怪扑杀 / 牛头抬腿 / 蛇甩尾 **预警音可读**  
4. VO 出时 BGM duck；字幕可关 VO 仍可读  
5. 总表 draft 种子可被 Addressables 同名挂接
