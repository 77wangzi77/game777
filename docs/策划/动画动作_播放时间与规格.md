## 0. Meta · VR 与跳过

### 0.1 帧与秒

| 项 | 约定 |
|----|------|
| 对表 FPS | **30**（1s = 30f） |
| 时长写法 | 优先精确单值（如 0.45s），技能三段和 = clip 总长 |
| 循环 clip | `duration_s` = 单圈长度 |

### 0.2 VR 舒适（过场 / 战斗）

| 规则 | 说明 |
|------|------|
| 禁强制长转 | 无强制长时间旋转、高速推拉、落地甩头 |
| CS/SC 坐姿 | 全部可坐姿看完 |
| BI | **锁移动**；保留 HMD yaw，**限角速度**；可格挡预备 |
| KO | 短锁 2–5s |
| ST | UI 可点；不抢 HMD |
| 战斗预警 | 敌危险招前摇可读；扑杀不停扑距 &lt;1.2m；冲撞/甩尾给逃点 |

### 0.3 跳过规则

| 标记 | 含义 |
|------|------|
| ★ / `no_skip=是` | 不可跳过镜（旁白关键句、兽名首次等） |
| 其余 | `Cutscene.Skip()` 可跳；跳过后仍写既定任务 flag（与剧情动画设计一致） |
| 一周试玩 | 战斗段可整段 `Combat.SkipAvailable`；过场仍按 ★ |

### 0.4 一周试玩 P0（灰模 QM）

| 优先级 | 过场 ID | 总时长 | 备注 |
|--------|---------|--------|------|
| **P0** | `CS_01_intro` | **25.0s** | 入关必播 |

## 5. 验收标准（可测）

1. `BI_01_yard` Timeline 总长 **8.0±0.2s**；结束后伤害盒激活。  
2. `CS_01_intro` **25.0±0.3s**；★旁白镜不可 Skip。  
3. `ANIM_ghost_atk_pounce`：`ShadowStretch` 峰值在 **t=0.25±0.03s**；身体停扑距 ≥1.2m。  
4. `ANIM_mino_charge_windup` 时长 **≥0.40s**（规格 **0.45s**）；无抬腿不得进 loop。  
5. `ANIM_serpent_atk_tail` windup **≥0.35s**（规格 **0.40s**）；与 `VFX_serpent_tail_tele` / `SND_serpent_tail_tele` 同帧。  
6. 技能三段之和 = 对应 clip `duration_s`（误差 ≤1 帧@30）。  
7. 无强制长转；CS/SC 坐姿可完播；BI 仅锁移动保留限速 HMD yaw。  
8. P0 过场与 P0 clip 可进 Addressables 灰模包挂名。
