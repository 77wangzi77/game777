# 小地图系统（细则）

> 对接：`主要系统大纲.md` §6  
> 平台：PCVR · Unity  
> 状态：按你口述锁定若干硬规则

---

## 1. 一句话

雷达式小地图：只读显示角色位置与朝向、雷达范围内的建筑/地形/关卡信息，以及范围内的 NPC/怪物；**无放大、不可点击**。

---

## 2. 硬规则（已确认）

| 规则 | 说明 |
|------|------|
| **无放大** | 不提供缩放、滚轮放大、双指捏合、按钮放大；固定显示比例 |
| **不可点击** | 小地图整体与内部图标均不响应点击/射线点击；不打开大地图、不选目标、不导航点击 |
| 只读 | 纯信息展示；交互进任务/锁定走别的系统 |

---

## 3. 角色显示

| 项 | 规则 |
|----|------|
| 位置 | 显示**当前角色**在小地图上的位置 |
| 形状 | **箭头形状** |
| 颜色 | **绿色** |
| 朝向 | **箭头朝向始终与角色操作方向一致**（跟移动/面向输入对齐，不是跟头显随便晃，除非操作方向=该轴向） |
| 更新 | 每帧或固定 tick 同步世界坐标 → 地图 UV/本地坐标 |

### 3.1 朝向定义（程序）

- 取角色 **逻辑移动朝向 / 操作朝向**（`moveYaw` 或角色根 `forward` 的水平投影）  
- 映射为箭头旋转：`arrowAngle = yaw`  
- VR：瞬转后箭头立即跟上；传送完成后对齐落点朝向  

---

## 4. 雷达范围与地形信息

| 项 | 规则 |
|----|------|
| 范围 | 以角色为中心的雷达半径 `radarRadius`（米，待填默认如 40） |
| 显示内容 | 雷达范围内的 **建筑、地形、关卡信息**（房间块、路网、关卡锚点等） |
| 范围外 | 不绘制或剪裁；不做「全图解锁放大查看」 |
| 图层 | 地形底图 / 建筑轮廓 / 关卡标记（任务点可另色，但仍不可点） |

---

## 5. NPC / 怪物显示

| 项 | 规则 |
|----|------|
| 检测 | 雷达范围内的 NPC 或其他怪物 |
| 样式 | **红色原点** |
| 刷新 | 进入范围出现，离开范围消失（或淡出） |
| 区分 | 默认 NPC/怪物统一红点；若需友军另色 → 待填（当前按口述仅红点） |
| 不可点 | 红点不可选中、不可锁定（锁定走战斗锁定键） |

---

## 6. UI 与摆放（建议）

| 项 | 建议 |
|----|------|
| PC/调试 | 屏幕角固定圆形/方形雷达；无缩放控件 |
| VR | 腕托或腰牌雷达；**不占中央视野**；仍无放大、不可用激光点选 |
| 输入 | 不绑定任何 Click / PointerClick 到小地图 Raycast Target → **关闭 raycast** |

---

## 7. 配置结构（草案）

```json
{
  "minimapId": "MM_default",
  "radarRadius": 40.0,
  "fixedScale": 1.0,
  "allowZoom": false,
  "clickable": false,
  "playerMarker": {
    "shape": "arrow",
    "color": "#00FF66",
    "follow": "moveYaw"
  },
  "hostileOrNpcMarker": {
    "shape": "dot",
    "color": "#FF3333",
    "includeTags": ["NPC", "Enemy", "Monster"]
  },
  "layers": ["terrain", "building", "levelInfo"],
  "updateHz": 20
}
```

| 字段 | 说明 |
|------|------|
| allowZoom | **必须 false** |
| clickable | **必须 false**；UI 关闭 raycast |
| fixedScale | 固定比例，无运行时修改入口 |
| playerMarker.follow | `moveYaw` = 与操作方向一致 |
| hostileOrNpcMarker | 红点 |

---

## 8. 与战斗 / 任务边界

| 不做 | 原因 |
|------|------|
| 点小地图移动/寻路 | 不可点击 |
| 点红点锁定敌人 | 不可点击；锁定用战斗输入 |
| 放大看全关 | 无放大；全关信息用别的只读面板（若以后要另立需求） |

---

## 9. 验收

1. 玩家为**绿色箭头**，位置正确  
2. 转动操作方向时箭头同步转，与操作方向一致  
3. 半径内可见建筑/地形/关卡信息；半径外不可靠放大查看  
4. 范围内 NPC/怪物为**红色原点**  
5. **无法放大**（无控件、滚轮无效）  
6. **无法点击**（点地图无响应、不选中、不导航）
