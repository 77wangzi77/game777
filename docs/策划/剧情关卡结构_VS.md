# 剧情关卡结构 · Vertical Slice（复杂叙事版）

> 用户确认方向（2026-11-02）：**剧情要复杂**。  
> 仍假设：原创同调气质；战斗极轻（服务叙事，非刷怪）。拍板「对标某部 / 战斗比重」前按此推进。

## VS 一句话

**《残简三声》**：月夜驿站不是过路歇脚，而是三方谎言交汇点。玩家在 15–25 分钟内发现「失窃」是假案，竹简有三份抄本，每人只说了三分之一真话；一次关键选择会改写离关后的世界状态（为第二章埋伏笔）。

## 叙事复杂度设计（本 VS 必达）

| 层 | 内容 | 玩家如何感知 |
|----|------|--------------|
| 表象案 | 掌柜称竹简被盗 | 开场主线 |
| 信息差 | 掌柜 / 旅客 / 哑仆 三人口径互相矛盾 | 对照笔记或回忆提示 |
| 物件说谎 | 三件线索物中有一件是栽赃 | 检视文案互相打架 |
| 身份反转 | 「过路剑客」可能被当成接应人 | 对话选项解锁新枝 |
| 时间压力 | 子时前必须做出站队，否则默认「谁都不帮」坏结局钩子 | UI 时辰或远处更鼓 |
| 双结局钩 | 追伪贼 / 护真简 / 揭穿掌柜（第三条需凑齐矛盾证据） | 第三条是「复杂」验收点 |
