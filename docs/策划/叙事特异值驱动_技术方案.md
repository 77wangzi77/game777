## 1. 目标与边界

### 1.1 目标

在剧情运行时抓取**特异值**（异常 / 转折 / 关键变量），据此驱动关卡模式切换与角色/系统行为判断；让玩家在戴头显时**可感**叙事变化，且 `expose` 路径由条件解锁而非隐藏菜单。

### 1.2 服务对象

| 项 | 约定 |
|----|------|
| VS | L01《残简三声》· 15–25 分钟 |
| 循环 | 入关→多方对话→探索/轻解谜→对质→站队→过场 |
| 状态机 | `Boot → Arrive → CaseBrief → Investigate{Explore\|Talk\|Puzzle} → Confront? → Choice → Outro(flag) → Save` |
| flag | `chapter1_flag` ∈ {chase, guard, expose, none} |

### 1.3 本岗边界

| 做 | 不做 |
|----|------|
| 特异值表、模式切换规则、行为判断逻辑、节拍×特异值管线、叙事交付模板、与程序的数据契约 | 战斗数值、开放世界、引擎 C# 实现全文、另造与现有 QE/flag 冲突的结局 |
| 旁白/引导文案槽、对话条件挂钩说明 | 改写已定对话树剧情内容 |

邻岗：策划（任务/验收）· 关卡概念（空间节点）· VR场景 · Unity程序 · UI美术。本岗交付**规则与数据表**，程序按契约挂事件。

## 2. 系统总览

一句话：事件 → 特异值采集 → Affect → **五通道感知（一级输入）** → 模式评估 → 行为判断 → 表现钩子；LLM 建议经 Validator，硬门禁本地强制。

```
[XR 交互 / 对话选项 / 时限更鼓]
          │
          ▼
   ┌──────────────┐
   │ 事件总线 Event │  Narrative.* / Level.* / Dialogue.*
   └──────┬───────┘
          ▼
   ┌──────────────┐
   │ 特异值采集器   │  写入 SessionSV + 可选 GameState
   └──────┬───────┘
          ▼
   ┌──────────────┐
   │ 模式评估器     │  规则表 → 目标 Mode（可强制）
   └──────┬───────┘
          ▼
   ┌──────────────┐
   │ 行为判断器     │  开/禁对话枝 · 节奏加压 · 系统反馈
   └──────┬───────┘
          ▼
   旁白 / 对话节点 / 微光·焦点光 / 时辰 UI / Outro(flag)
```

与程序 Level 映射：叙事 Mode ≈ 任务流状态机同名阶段；`Investigate` 内子态 `Explore|Talk|Puzzle` 由关卡触发器上报，不另建叙事状态机。

## 3. 特异值模型（核心）

### 3.1 三类定义

| type | 含义 | 玩家感知 | 典型写入 |
|------|------|----------|----------|
| `Anomaly` | 感知异常 | 声/光/文案「今夜不对」 | 会话标记；可加压引导 |
| `Pivot` | 叙事转折 | 假案立起、矛盾对成立、对质关闭 | 任务进度 QM*、可进下一模式 |
| `Critical` | 关键变量 / flag | 选项出现/消失、离关钩差异 | `has_QE*`、`host_suspect`、`chapter1_flag` 等 |

### 3.2 字段约定

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 稳定英文蛇形，前缀 `SV_` |
| `name_zh` | string | 中文名 |
| `type` | enum | Anomaly / Pivot / Critical |
| `source` | enum | beat / space / npc / item / system |
| `trigger` | string | 触发条件（事件或谓词） |
| `payload` | object | 附加数据（如证据 id、增量） |
| `weight` | int | 评估权重（默认 1；强制切模式用高值） |
| `priority` | int | 同帧多条时排序（大优先） |
| `ttl` | enum | `instant`（仅当帧）/ `session` / `persist` |
| `consumes` | bool | 是否消费后移除（防重复刷行为） |
| `writes` | string[] | 写入的 GameState / 会话键 |

### 3.3 L01 首版特异值表

| id | 中文名 | type | source | 触发 | writes | 驱动效果 |
|----|--------|------|--------|------|--------|----------|

### 3.4 证据点计数（供 QM2）

程序侧建议：`evidence_count = Σ has_QE1…QE5`；`char_deep_count` = QC 深度≥1 的条数（或深度≥2 的对话完成数，与策划任务流「深谈≥2」对齐时取对话完成次数）。特异值 `SV_qm2_ready` 只读该计数，不另造证据。

## 3.5 感知通道 × 叙事特异量（Affect）

> 细则与矩阵完整版见总册；此处为 L01 契约摘要。架构为 **LLM-first 建议 + 本地硬门禁**（见 Unity 专章三路线）。

### 感知通道（5）

| 通道 | 枚举 | PCVR 载体 | 备注 |
|------|------|-----------|------|
| 听 | `Hear` | 风铃、更鼓、旁白 VO、空间音频 | |
| 说 | `Speak` | 对白选项、★句、语气长短 | |
| 看 | `See` | 微光、焦点光、高亮、视线引导 | |
| 味 | `Taste` | 文案联觉（墨腥/酒苦等） | **联觉替代** |
| 感觉 | `Feel` | 手柄震动、传送舒适度、近距体感 | |

`PerceptState` 例：Hear muffled/sharp；Speak silent/urgent；See dim/focused/tunnel；Taste flat/keen；Feel numb/tense/pressure。

### 叙事特异量 Affect（7）

| id | 含义 | 与现有 |
|----|------|--------|
| `score` | **线索/证据可信度积分**（←证据点计数） | **非**战斗得分 HUD |
| `winLose` | 对质/抉择态势 -1/0/1 | |
| `death` | 叙事死亡压迫 0–1 | 服务 none 坏钩感 |
| `fear` / `joy` | 恐惧 / 松弛 | 不显式弹出数值 UI |
| `suspect` / `trust` | 映射 `host_suspect` / `trust_mute` | 不拆 Critical 原键 |

### 判断规则（摘要）

| 特异量 | Hear | Speak | See | Taste | Feel |
|--------|------|-------|-----|-------|------|
| fear↑ | Sharp | Urgent 短句 | Tunnel | Keen | Tense |
| joy↑ | Normal | Calm | Focused | Keen暖 | Neutral |
| death↑ | 更鼓突出 | 压迫 | Dim | Flat | Pressure |
| score↑ | — | 对质枝可开 | 证据微光 | — | — |

### SV 主通道标注（不改 23 条 id）

| 主通道 | 代表 SV |
|--------|---------|
| Hear | `SV_bell_wrong_tone`, `SV_watch_drum`, `SV_force_choice` |
| Speak | `SV_case_erected`, `SV_timeline_*`, `SV_host_suspect_inc`, `SV_guest_turned`, `SV_flag_*` |
| See | `SV_ink_wet`, `SV_box_lock_reversed`, `SV_mute_rule_slip`, `SV_expose_ready`, `SV_outro_triggered` |
| Taste | `SV_ink_wet`（墨腥联觉）、旅客请酒相关文案槽 |
| Feel | `SV_box_lock_reversed`, `SV_trust_mute`, 更鼓加压 |

### 程序键补丁

- `affect.score|winLose|death|fear|joy|suspect|trust`
- `percept.hear|speak|see|taste|feel` + `percept.pressure`
- 事件：`Narrative.AffectChanged`、`Narrative.PerceptChanged`（及既有 Narrative.*）
- 默认不对玩家显式「恐惧值」；LLM 超时走规则降级


## 4. 关卡 / 模式切换规则

### 4.1 模式枚举与程序映射

| 叙事 Mode | 任务流状态 | 说明 |
|-----------|------------|------|
| `Arrival` | Arrive | N1 入关 |
| `CaseBrief` | CaseBrief | N2 听假案 |
| `Investigate` | Investigate{Explore\|Talk\|Puzzle} | N3–N5 自由回跳 |
| `Confront` | Confront? | N6；可跳过 |
| `Choice` | Choice | N7 |
| `Outro` | Outro(flag)→Save | N8 |

`Boot` 由程序启动负责，叙事层从 `Arrival` 起订。

### 4.2 规则表

| 规则 id | 条件 | 目标 Mode | 强制? | 玩家可感反馈 |
|---------|------|-----------|-------|--------------|
| R01 | 入关传送完成 | Arrival | 是 | 旁白；风铃 Anomaly |
| R02 | `SV_case_erected` | Investigate | 是 | 掌柜派查；微光可指向侧廊/后院 |
| R03 | `SV_qm2_ready` 且玩家开对质 | Confront | 否 | 焦点光压旅客侧可选；对质枝开放 |
| R04 | 对质中玩家取消 | Investigate | 否 | 回探索；记 `SV_confront_skipped` 仅当最终未完成对质 |
| R05 | `SV_contradiction_pair` 且未对质 | （仍 Investigate） | 否 | 旁白矛盾句；弱提示可回堂 |
| R06 | `SV_watch_drum` | （保持当前） | 否 | 时辰 UI + 更鼓音量升 |
| R07 | `SV_force_choice` 前 | 先 `SV_last_confront_window` | 是（时序） | 30s 窗提示「尚可一问」 |
| R08 | 30s 窗结束或时限到 | Choice | **是** | 回堂/外廊抉择位；选项≤3 |
| R09 | 玩家主动子时抉择（未到点） | Choice | 否 | 同 H3 |
| R10 | Choice 选定或 `SV_flag_none` | Outro | 是 | 引导竹林口；按 flag 旁白 |
| R11 | `SV_outro_triggered` | Save（程序） | 是 | 过场结束存档 |

**硬规则（对齐任务流）：**

1. `Investigate` 内堂内↔侧廊↔后院↔灶房**自由回跳**，叙事不锁死线性。  
2. 更鼓到点**强制** `Choice`；可留 **30s** 最后对质窗。  
3. `Confront` **可跳过**；跳过（或从未完成 QM3）则**锁死 expose**，即使 `SV_expose_ready`。  
4. expose 选项仅当：`SV_expose_ready` ∧ ¬`SV_confront_skipped` ∧ `SV_confront_done`（或等价：已完成一次对质对话）。

## 5. 行为判断逻辑

### 5.1 输入 / 输出

**输入：** 当前 Mode · 剧情进度（QM0–QM5）· 特异值集合 · NPC 深度/可信度（`host_suspect`、`trust_mute`、`guest_turned`、QC 深度）

**输出：**

- 可触发枝 / 禁用枝（对话条件）  
- 节奏加压等级 `pressure` ∈ {0,1,2}（0 常态 · 1 弱提示 · 2 更鼓强压）  
- 系统行为：引导微光、焦点光、时辰 UI、证据短提示  

### 5.2 对话枝门控（对齐对话节点，不另造剧情）

| NPC | 枝 | 启用条件 | 禁用时行为 |
|-----|----|----------|------------|
| 掌柜 H1b | 问清何时 | CaseBrief / 开场树 | — |
| 掌柜 H2a | 墨色不像旧物 | Investigate ∧ `has_QE3` | 选项不显示 |
| 掌柜 H2b | 亥时响动 | Investigate ∧ `has_QE2` | 不显示 |
| 掌柜 HX | 对质亥/子 | Confront ∧ `SV_contradiction_pair` | 无法开对质 |
| 掌柜 HXa | 「知道太多」 | HX ∧ `host_suspect≥1` | 走 HXb 弱提示哑仆 |
| 掌柜 H3-G | 揭穿 | Choice ∧ expose 硬规则 | 选项不显示（不灰显剧透） |
| 旅客 G1 | 亥时 | 请酒或出示泥印 | 停留 G0 |
| 旅客 G2 | 反水 | `has_QE5` ∨ `host_suspect≥1` | 不显示 |
| 哑仆 M1–M3 | 信任链 | 见对话节点表 | 无信任则无字条 |

### 5.3 角色 / 旁白行为切换（决策表）

| 特异值变化 | 掌柜 | 旅客 | 哑仆 | 旁白 / 系统 |
|------------|------|------|------|-------------|
| `SV_bell_wrong_tone` | — | — | — | 入关旁白；微光堂门 |
| `SV_case_erected` | 进入「可有眉目」待机 | 可闲话 | 可灶房 | 模式 Investigate |
| `SV_contradiction_pair` | 试探更敏感 | — | — | 矛盾旁白；pressure≥1 |
| `SV_host_suspect_inc` | 对质走锋利枝 | G2 门槛降 | — | 证据回忆可标嫌疑（只读） |
| `SV_ink_wet` / `SV_box_lock_reversed` | H2 对应枝 | — | — | 短提示；微光可回堂 |
| `SV_trust_mute`→字条 | — | — | 给 QE5 | 短提示 |
| `SV_expose_ready` | — | — | — | **不**弹「可揭穿」；仅 Choice 显第三选项 |
| `SV_watch_drum` | 台词可催促（若回堂） | 更忐忑待机 | — | 时辰 UI；更鼓；pressure=2 |
| `SV_confront_skipped` | Choice 无 G | — | — | — |
| `SV_flag_*` | 按枝离场演出 | 按 flag 在场/消失 | 按 flag | 四向离关旁白 |

### 5.4 伪代码（模式评估 + expose 门）

```
on Event e:
  raise MatchingSpecialValues(e)  # 写入 writes
  if SV_force_choice and mode != Choice and mode != Outro:
    open LastConfrontWindow(30s) or go Choice
  if SV_case_erected and mode == CaseBrief:
    setMode(Investigate)
  if playerRequestsConfront and SV_qm2_ready and SV_contradiction_pair:
    setMode(Confront)
  if confrontCancelledOrNeverFinished at ChoiceEntry:
    mark SV_confront_skipped
  refreshDialogueGates()
  refreshPressureAndUX()

canShowExposeOption =
  has_QE1 and has_QE2
  and (has_QE3 or has_QE4)
  and has_QE5
  and confront_done
  and not confront_skipped
```

## 6. 节拍管线（空间 × 叙事 × 特异值）

| 节拍 | 空间块 | 玩家动作 | 采集特异值 | 可能模式跳转 | 时长 |
|------|--------|----------|------------|--------------|------|
| N1 入关 | ENV_L01_Porch | 传送→听铃/旁白→进堂 | `SV_bell_wrong_tone` | Boot→Arrival→(进堂)CaseBrief | ~2′ |
| N2 假案 | Hall·掌柜 | 主对话树 | `SV_timeline_host`、`SV_case_erected` | CaseBrief→Investigate | ~3′ |
| N3 闲话 | Hall·旅客 | 闲话/请酒/泥印 | `SV_timeline_guest`、(`SV_contradiction_pair`) | 仍 Investigate；可提示 Confront | ~2′ |
| N4 搜证 | Wing/Upper/Yard | 检视线索、匣解谜 | `SV_ink_wet`、`SV_box_lock_reversed` | Investigate 内 Explore/Puzzle | ~5′ |
| N5 暗线 | Kitchen | 递水、字条、钥匙 | `SV_trust_mute`、`SV_mute_rule_slip` | 仍 Investigate；可凑 `SV_expose_ready` | ~2′ |
| N6 对质 | Hall 回跳 | 矛盾证据对质 | `SV_host_suspect_inc`、`SV_confront_done` / skipped | →Confront?→回 Investigate | ~3′ |
| N7 抉择 | Hall/Porch | chase/guard/expose | `SV_watch_drum`/`SV_force_choice`、`SV_flag_*` | →Choice | ~2′ |
| N8 离关 | Bamboo | 触发过场 | `SV_outro_triggered` | →Outro→Save | ~2′ |

合计目标 15–25′。expose 空间门槛（关卡概念）：须至少离开堂内一次（后院或上房）+ 进灶房——由 QE3/QE4 + QE5 自然保证，特异值层不另加地理锁。

## 7. 数据与程序对接契约

### 7.1 建议资产形态

| 资产 | 路径建议（对齐骨架） | 用途 |
|------|----------------------|------|
| `SpecialValueDef` SO 或 JSON | `Assets/_Project/ScriptableObjects/Narrative/` | 特异值静态定义（§3.2 字段） |
| `ModeTransitionRule` SO/JSON | 同上 | §4.2 规则行 |
| `BeatPipeline` SO/JSON | 同上 | §6 节拍行 |
| 运行时 | `Scripts/Core` GameState + `Scripts/Level` 事件 | 读写键、抛事件 |

叙事岗只维护表数据；C# 由 Unity 岗实现。

### 7.2 事件名约定

| 事件 | 何时抛 | 载荷建议 |
|------|--------|----------|
| `Narrative.AnomalyRaised` | Anomaly 类特异值触发 | `{ id, source }` |
| `Narrative.PivotRaised` | Pivot 触发 | `{ id }` |
| `Narrative.CriticalChanged` | Critical 写入后 | `{ id, writes }` |
| `Narrative.ModeChanged` | 模式切换 | `{ from, to, forced }` |
| `Narrative.PressureChanged` | pressure 变更 | `{ level }` |
| `Narrative.ExposeGateChanged` | `canShowExposeOption` 变化 | `{ ready: bool }`（UI **勿**直接剧透文案） |
| `Level.WatchDrum` | 时限警告/到点 | `{ phase: warn\|force\|window }` |
| `Dialogue.GateRefresh` | 门控重算后 | `{ npcId }` |

### 7.3 GameState 键清单

**已有（必须保持）：**  
`has_QE1`…`has_QE5` · `trust_mute` · `guest_turned` · `host_suspect` · `chapter1_flag`

**任务进度：**  
`qm0_done`…`qm5_done`（或等价任务系统状态）

**Affect / Percept（会话为主；suspect/trust 可与原键同步）：**  
`affect.score|winLose|death|fear|joy|suspect|trust` · `percept.hear|speak|see|taste|feel` · `percept.pressure`

**特异值派生（建议前缀 `sv.`）：**  
`sv.bell_heard` · `sv.contradiction` · `sv.expose_ready` · `sv.confront_skipped` · `sv.drum_warn` · `sv.last_window` · `confront_done`（可用 `qm3_done` 代替）

### 7.4 存档策略

| 类别 | 持久化? | 说明 |
|------|---------|------|
| `chapter1_flag`、QE/QC 相关键、`trust_mute`、`guest_turned`、`host_suspect`、QM 完成 | **是** | 通关/中断续玩；章2吃 flag |
| `sv.bell_heard`、`sv.drum_warn`、`sv.last_window`、instant Anomaly | **否**（仅会话） | 重进关可再播氛围 |
| `sv.contradiction`、`sv.expose_ready`、`sv.confront_skipped` | **建议是** | 避免读档后门控不一致；也可由 QE/对质状态重算 |

重算优先：能从 QE + 对质完成态推导的，读档后跑一次 `refreshGates()`，减少脏标记。

## 9. 首版验收

| # | 标准 | 验证方式 |
|---|------|----------|
| 1 | 戴头显可感特异值 **≥3** | 至少：风铃异常、矛盾对旁白、更鼓加压（或墨未干/匣锁其一） |
| 2 | expose 由特异值条件解锁，非隐藏菜单 | 缺任一 QE 条件或跳过对质时无第三选项；凑齐且对质完成后出现 |
| 3 | 四 flag 离关可区分 | chase/guard/expose/none 旁白与镜头朝向不同 |
| 4 | 程序可按契约挂事件 | `Narrative.AnomalyRaised` / `ModeChanged` / Critical 写入可在 Editor 冒烟日志见到 |
| 5 | 与任务流一致 | Investigate 自由回跳；到点强制 Choice；Confront 可跳过则无 expose |
