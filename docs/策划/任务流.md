# 任务流（复杂叙事版）

## 任务网总览

主线不是一条链，而是 **假案主线 + 证据线 + 人物线** 三股交织；证据线达标才能解锁「揭穿」结局。

```
Q_MAIN 假案（始终可见）
   ├─ Q_EVID 证据板（并行）
   │     ├─ E1 掌柜口述时间
   │     ├─ E2 旅客口述时间（矛盾）
   │     ├─ E3 残页墨色
   │     ├─ E4 伪匣机关
   │     └─ E5 哑仆字条（需钥匙/信任）
   └─ Q_CHAR 人物线（并行）
         ├─ C_host 掌柜可信度
         ├─ C_guest 旅客动机
         └─ C_mute 哑仆身世
→ Q_CONFRONT 对质（条件）
→ Q_CHOICE 站队（三分支）
→ Q_OUTRO 离关
```

## 主线任务表

| ID | 任务名 | 触发 | 完成条件 | 卡住处理 | 产出 |
|----|--------|------|----------|----------|------|
| QM0 | 落脚 | 入关 | 进入堂内交互圈 | 微光引导 | 解锁 QM1 |
| QM1 | 听假案 | 与掌柜开对话 | 走到「竹简失踪」节点 | 可重开 | 解锁 QE* / QC* |
| QM2 | 查今夜 | QM1 后 | 证据点 ≥3 **或** 人物线深谈 ≥2 | 弱提示：旅客欲言又止 | 可进对质 |
| QM3 | 对质 | QM2 且证据矛盾对 ≥1 | 完成一次对质对话 | 可取消回探索 | 解锁第三选项条件判定 |
| QM4 | 子时抉择 | 时限到或玩家主动 | 选 chase / guard / expose | 超时 → `none` 坏钩 | 分支 flag |
| QM5 | 夜奔 | QM4 后 | 到竹林口触发对应过场 | 无 | 通关+存档 |

## 证据线（QE）

| ID | 名称 | 获得方式 | 叙事作用 | 与谁矛盾 |
|----|------|----------|----------|----------|
| QE1 | 掌柜时间线 | 对话自动 | 「子时前失窃」 | QE2 |
| QE2 | 旅客时间线 | 旅客深谈 | 「亥时已听到后院响动」 | QE1 |
| QE3 | 残页墨未干 | 检视客房残页 | 抄本是今夜现写 | 掌柜「旧藏」说辞 |
| QE4 | 匣锁反装 | 后院解谜成功 | 匣是给人发现的 | 真简不在匣内 |
| QE5 | 哑仆字条 | 灶房；需先得 C_mute≥1 | 「三角，一真二假」 | 指向三抄本结构 |

**揭穿解锁条件**：持有 (QE1∧QE2) 矛盾对，且 (QE3∨QE4)，且 QE5 —— 即至少「时间矛盾 + 物证 + 规则提示」。

## 人物线（QC）

| ID | 对象 | 深度 0→2 | 深度奖励 |
|----|------|-----------|----------|
| QC_h | 掌柜 | 试探谎言选项 / 出示 QE3 | 可信度↓；对质枝变锋利 |
| QC_g | 旅客 | 请酒或出示脚印泥 | 吐露「被雇来作证」 |
| QC_m | 哑仆 | 递水、不告发、还其木牌 | 给字条 QE5；可开上房 |

## 分支 flag（存档）

| flag | 含义 | 过场钩子（给章2） |
|------|------|-------------------|
| `chase` | 追「贼」 | 竹林遇的是替身；真简被掌柜转移 |
| `guard` | 护匣 | 护住假简；真线在旅客包袱 |
| `expose` | 揭穿掌柜 | 掌柜翻脸求共谋；玩家拒/允再生枝 |
| `none` | 超时未选 | 三人同时消失；抄本被毁钩子 |

## 状态机（程序）

`Boot → Arrive → CaseBrief → Investigate{Explore|Talk|Puzzle} → Confront? → Choice → Outro(flag) → Save`

- `Investigate` 内自由回跳；更鼓到点强制切入 `Choice`（可给 30s 最后对质窗）。
- `Confront` 可跳过；跳过则无法 `expose`。
