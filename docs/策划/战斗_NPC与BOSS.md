## 1. 分层总览

| 层级 | 定位 | 单场时长 | 失败后果 | 首章是否出现 |

| 氛围 NPC | 不可击杀 / 仅演出 | — | — | ✓（掌柜等） |

`Idle → Alert → Approach → AttackCombo → Recover →（低血）FleeOrDesperado → Dead`

## 5. Boss

### 5.1 Boss 设计模板（每个 Boss 必填）

1. **叙事身份**：为何打、败后世界怎么变  
2. **舞台**：空间尺寸、可摔落/可破坏物  
3. **阶段**：通常 2–3；转阶段演出可坐姿看  
4. **可读招**：颜色/音效/肢体预兆 ≥0.35s  
5. **VR 特规**：禁止长时间强制转向；AOE 给传送逃点  
6. **二周目钩**（可选）：隐藏破招

### 5.2 Boss 名单（四章预埋）

| ID | 章 | 名称 | 身份真相 | 核心机制 | 阶段 | 败后剧情 |

| B_host | 1 可选 | 「掌柜」武装态 | 假案导演 | 柜台障碍+扔暗器；对话可跳过战斗 | 1–2 | expose 线专属 |
| B_bamboo | 2 | 接骨人 | 替身幕后 | 竹林视野遮挡、分身脚印 | 2 | 真简线索 |
| B_shrine | 3 | 祠下无名 | 改史执刀人 | 铭文地面危险区、点名点灭 | 3 | 世界观摊牌 |

### 5.4 Boss 通用阶段机

`Intro(不可伤) → P1 → ThresholdCutscene → P2 → (可选 P3) → FinisherDialouge → LootOrFlag`

- Intro/转阶段：玩家伤害无效，可跳过演出  
- Finisher：默认对话收束，不强制 QT

### 5.5 章1「掌柜」Boss（若 expose）

| 项 | 内容 |
|----|------|
| 触发 | flag 走向 expose 且拒共谋 |
| 舞台 | 堂内推开桌椅形成环 |
| P1 | 暗器点射 + 近战拍桌 |
| P2 | 呼叫武卫×1（可先打武卫） |
| 劝降 | 气势检定或出示 QE5 字条 → 直接收束 |
| 败后 | host_deal 分支；章2敌友改写 |

## 7. 验收（战斗 NPC+Boss）

1. 杂兵教程关：不看攻略可学会轻击、格挡、逼近弓手  
2. 精英假破绽至少坑玩家一次，但第二次可读  
3. 任一 Boss：转阶段有逃点；无强制连续旋转  
4. 劝降/唬退路径真实可走（非摆设）  
5. 失败重生不丢主线进度
