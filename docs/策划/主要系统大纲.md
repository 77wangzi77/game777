## 1. 角色系统

### 1.1 角色构成

| 模块 | 内容 | 说明 |
|------|------|------|
| 身份 | 过路剑客（可被剧情改写） | 与章节 flag 挂钩 |
| 基础属性 | 体魄 / 灵力 / 悟性 / 气势 | 影响战斗与少量检定对话 |
| 资源 | 气血、灵力、体力（冲刺/格挡） | VR 舒适：体力限制急转 |
| 姿态 | 站立 / 坐姿过场 / 战斗架势 | 坐姿可完成对话与过场 |
| 装备槽 | 主手武器、副手（符/盾/空）、饰品×1、衣装 | 首版衣装只换外观 |
| 技能栏 | 主动技 2 + 奥义 1 + 被动 2 | VS 可只开 1 主动 |

### 1.2 成长

- 来源：关卡目标、关键抉择、隐藏证据（非刷怪为主）
- 等级：1–10（首章封顶 3）
- 加点：每级 2 点，可重置（客栈一次）

### 1.3 与剧情接口

- `chapter_flag`、`trust_*`、`host_suspect` 等不进战斗面板，进「见闻录」
- 身份揭晓可解锁被动（如「听谎」对话提示）

### 1.4 待填（给你改）

- 玩家是否可自创姓名/外观？
- 是否要多主角切换？

## 2. 战斗系统

### 2.1 设计原则（PCVR）

- 移动：传送为主；战斗区内允许有限滑步
- 交互：手柄挥砍 / 指向施法 / 格挡（副手）
- 节奏：遭遇短（30–90 秒），服务剧情节点
- 失败：气血归零 → 就近石灯重生，剧情不倒退（可掉「气势」）

### 2.2 战斗流程

`遇敌演出 → 锁定/自由瞄准 → 攻防循环 → 破绽/虚弱 → 结算与掉落/对话`

### 2.3 动作与输入（草案）

| 动作 | 输入 | 消耗 | 备注 |
|------|------|------|------|
| 轻击 | 主手挥砍 | 无 | 连段 3 |
| 重击 | 蓄力挥砍 | 体力 | 可破轻防 |
| 格挡 | 副手举起 | 体力/击中 | 完美格挡弹反 |
| 闪避 | 短滑步/瞬移点 | 体力 | 有 CD，防晕动 |
| 术法 | 副手指向 + 键 | 灵力 | 远距控制 |
| 奥义 | 双键 + 姿 | 灵力大 | 过场可跳过特效 |

### 2.4 敌人archetype（首章）

| 类型 | 作用 | 示例 |
|------|------|------|
| 威慑单位 | 不战可唬走 | 竹林黑影 |
| 杂兵 | 教操作 | 山贼 |
| 精英 | 关卡门神 | 假贼替身 |
| 不可击杀 | 剧情 NPC | 掌柜翻脸演出 |

### 2.5 待填

- 战斗比重：轻量 / 中等 / 关卡战斗为主？
- 是否要武器耐久、毒、异常状态？

## 4. 数值设计

### 4.1 基础属性区间（Lv1）

| 属性 | 初始 | 每级成长建议 | 战斗影响 |
|------|------|--------------|----------|
| 气血 | 100 | +15 | 承伤 |
| 灵力 | 50 | +8 | 术法次数 |
| 体力 | 80 | +5 | 闪避/格挡/重击 |
| 体魄 | 5 | +1 | 物理攻防 |
| 灵力值(智) | 5 | +1 | 术法强度 |
| 悟性 | 5 | +1 | 解谜提示强度、暴击 |
| 气势 | 5 | +1 | 威慑检定、弹反窗 |

### 4.2 伤害粗式（草案）

`物理伤害 ≈ (武器白字 + 体魄×k1) × 招式倍率 × (1 - 防减)`  
`术法伤害 ≈ (法器白字 + 灵力值×k2) × 技能倍率`

k1/k2、防减曲线：**待数值表第一版**（另表 `数值表_v0`）

### 4.3 经济（首章）

- 货币：碎银
- 来源：任务、搜刮、抉择赏金
- 汇点：客栈修理/提示符/一味伤药
- 禁止：战斗掉落通货膨胀（掉落以线索物为主）

### 4.4 待填

- 难度档：故事 / 标准 / 剑冢？
- 是否要独立「心境」条影响对话选项？

## 5. 关卡设计

### 5.1 关卡类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 叙事枢纽 | 多 NPC、证据网 | VS 驿站 |
| 探索廊道 | 线索 + 轻解谜 | 侧廊/后院 |
| 对峙场 | 短战斗或唬退 | 竹林口 |
| 过场边界 | 坐姿可看 | 竹林入夜 |

### 5.2 VS《残简三声》空间点（已有细稿）

外廊 → 堂内 → 侧廊/上房 → 后院 → 灶房 → 竹林口  
详见：`剧情关卡结构_VS.md` / `任务流.md`

### 5.3 通用关卡验收

- 无攻略可推进；卡关有弱提示
- 单关 15–25 分钟可断点
- 至少 1 处信息差可感；分支后果可感

### 5.4 待填

- 后续章场景列表优先级
- 解谜占比 vs 战斗占比（按章）

## 6. 小地图系统

### 6.1 VR 约束

- **不做**屏幕角永久小地图（易晕、挡视野）
- 采用：「罗盘腕托 + 可展开平面图 + 世界空间路标」

### 6.2 功能拆分

| 功能 | 表现 | 输入 |
|------|------|------|
| 方位 | 腕托罗盘（南针/任务亮点） | 抬腕自动 |
| 目标点 | 世界空间淡光柱（可关） | 设置开关 |
| 平面图 | 展开羊皮纸：本关房间拓扑 | 菜单或腰牌 |
| 未探索 | 雾面；关键剧情点可「听声」标记 | 自动 |
| 多楼层 | 驿站仅一层；祠堂章再开分层 | 后置 |

### 6.3 与任务/证据

- 任务目标：罗盘脉冲
- 已发现线索：平面图钉针（不剧透未发现）
- 战斗中：默认收起平面图，只留罗盘

### 6.4 待填

- 是否允许「全开图」作弊档？
- 路标亮度/颜色规范交 UI 美术
