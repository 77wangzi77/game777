## 1. 目标与边界

在剧情中抓取特异值，结合**五通道感知状态**与**叙事特异量（Affect）**，驱动关卡模式、NPC/系统行为与节奏；LLM 负责抽取/建议/文案，规则表负责 expose/flag/时限等硬门禁。

| 做 | 不做 |
|----|------|
| 框架模块、数据表字段、运行时顺序、LLM schema、分期、L01 走通样例、Unity 契约 | 战斗刷分、开放世界、完整 C# 工程、API Key 明文、另造结局 |
| 积分=线索/证据可信度 | 得分 HUD / 击杀分 |

旗标仍仅：`chapter1_flag` ∈ {chase, guard, expose, none}。

## 2. 架构总览（9 模块）

```
[1 EventBus] → [2 SV Collector] → [3 Affect Store]
        ↘         ↓                    ↓
      [4 Perception Grader] ←——— affect + state
                ↓
      [5 Mode Evaluator] ← Validator 硬门禁 + LLM 建议
                ↓
      [6 Behavior Arbiter] → [8 Presentation Hooks]
                ↑
      [7 Beat Timeline N1–N8]
[9 Save/Persist] 横切 GameState
LLM Client（API / Agent / Local）旁路进 2–6，经 Validator
```

| # | 模块 | 职责 |
|---|------|------|
| 1 | EventBus | 输入事件汇聚 |
| 2 | SV Collector | Anomaly/Pivot/Critical 采集 |
| 3 | Affect Store | score/winLose/death/fear/joy/suspect/trust |
| 4 | Perception Grader | Hear/Speak/See/Taste/Feel 状态 |
| 5 | Mode Evaluator | 模式切换 |
| 6 | Behavior Arbiter | NPC/旁白/系统行为 |
| 7 | Beat Timeline | N1–N8 节拍 |
| 8 | Presentation Hooks | 听音频·说选项·看光·味联觉·感震动 |
| 9 | Save/Persist | 持久化边界 |

**感知状态是一级输入**：ModeEvaluator / BehaviorArbiter 必须读 PerceptSnapshot，不得只读 QE。

## 3. 感知通道（5）

| 通道 | 枚举 | PCVR 载体 | 备注 |
|------|------|-----------|------|
| 听 | Hear | 空间音频、风铃、更鼓、旁白 VO | |
| 说 | Speak | 对白选项、★句、语气长短 | |
| 看 | See | 视线引导、高亮、焦点光、微光 | |
| 味 | Taste | 文案+联觉暗示 | **联觉替代**（无法真味觉） |
| 感觉 | Feel | 手柄震动、传送舒适度、近距交互体感 | |

PerceptQualia 例：Hear muffled/sharp；Speak silent/urgent；See dim/focused/tunnel；Taste flat/keen；Feel numb/tense/pressure。

## 4. 叙事特异量 Affect（7）

| id | 含义 | 与现有关系 |
|----|------|------------|
| score | 线索/证据可信度积分 | ← evidence_count；非战斗分 |
| winLose | 态势 -1/0/1 | 对质/抉择 |
| death | 死亡压迫 0–1 | none 坏钩叙事感 |
| fear | 恐惧 0–1 | 更鼓/矛盾加压 |
| joy | 快乐/松弛 0–1 | 信任递水等 |
| suspect | 掌柜嫌疑 | 归一 host_suspect |
| trust | 哑仆信任 | 映射 trust_mute |

默认不对玩家显式弹出恐惧值/积分 HUD；只走通道表现。

### 感知判断矩阵（摘要）

| Affect 变化 | Hear | Speak | See | Taste | Feel |
|-------------|------|-------|-----|-------|------|
| fear↑ | →Sharp | →Urgent 短句 | →Tunnel | →Keen（腥） | →Tense/震动 |
| joy↑ | →Normal | →Calm | →Focused | →Keen（酒暖） | →Neutral |
| death↑ / none 逼近 | 更鼓突出 | 选项压迫 | Dim+焦点堂 | Flat | Pressure |
| score↑（证据） | — | 可开对质枝 | 微光证据点 | — | — |
| winLose 对质优势 | — | 锋利枝 | 焦点压旅客 | — | — |
| suspect↑ | — | HXa | — | — | Tense |
| trust↑ | — | 哑仆字条 | 灶房微光 | — | — |

## 5. LLM-first 职责切分

| LLM | 本地规则/Validator |
|-----|-------------------|
| 抽 SV、评五通道、建议 Mode/行为、选/起草文案槽 | expose 条件、flag 枚举、时限强制 Choice、Investigae 回跳、存档、禁新结局 |
| 调用：事件触发，非每帧 | 超时/失败 → 规则降级 |

三路线（详见 Unity 专章）：CloudApi / AgentOrchestrator / LocalPrivate；接口 `ILLMNarrativeClient`。

---

## 6. 运行时更新顺序（单事件）

1. EventBus 收 GameplayEvent  
2. SV Collector 规则命中并 writes  
3. 若 enableOnEvent：异步 LLM（不阻塞 XR）  
4. 返回后 Validator.Sanitize  
5. AffectStore 应用 delta；Score 可由证据重算  
6. PerceptionGrader → PerceptSnapshot  
7. ModeEvaluator（硬门禁优先于 modeSuggest）  
8. BehaviorArbiter 刷新对话门控  
9. PresentationRouter 推听/说/看/味/感觉  
10. 必要时 Save 标记脏数据

## 8. L01 走通样例：时间矛盾对成立

**前置**：has_QE1=1（掌柜子时）；玩家完成旅客 G1 → has_QE2=1。

| 步 | 发生 | 结果 |
|----|------|------|
| 1 | Dialogue.NodeReached G1 | Collector 写 has_QE2；raise SV_timeline_guest |
| 2 | 系统检测 QE1∧QE2 | raise SV_contradiction_pair；Pivot |
| 3 | Affect | score+=；fear+= mild |
| 4 | LLM（可选） | perceptSuggest: Hear Sharp, See Tunnel, Speak Urgent；copy NB_contradiction；modeSuggest Confront forced=false |
| 5 | Validator | 允许建议；不改 flag |
| 6 | Percept | pressure≥1 |
| 7 | Mode | 仍 Investigate，对质可开（非强制） |
| 8 | Presentation | 旁白「两个人，两个时辰…」；弱微光回堂 |
| 9 | Behavior | 掌柜 HX 门控亮起（需玩家开对质） |

**expose 后续**：再齐 (QE3∨QE4)∧QE5 且完成对质 → SV_expose_ready；Choice 显第三选项。跳过对质 → 锁死 expose。

## 10. 数据表字段（实现粒度）

- **SV**：id, nameZh, type, source, trigger, payload, weight, priority, ttl, consumes, writes, channelPrimary, affectTags  
- **Affect**：affectId, min, max, default, persist, note  
- **PerceptRule**：whenAffectOp, channel, toQualia, priority  
- **ModeRule**：ruleId, condition, toMode, forced, feedback  
- **Beat**：beatId, space, actions, svIds, modeJump, duration  
- **CopySlot**：slotId, bind, textZh, synesthesia  
- **LlmConfig**：providerKind, baseUrl, model, timeoutMs, apiKeyEnvVar, enableOnEvent, fallbackToRules

## 11. 分期

| 期 | 内容 |
|----|------|
| **P0** | SV+Mode+四 flag+硬 expose；规则跑通；LLM 旁路只打日志建议 |

## 12. 验收清单

1. 戴头显可感特异值≥3（含听/看至少各一）  
2. expose 条件解锁非隐藏菜单；跳过对质则无  
3. 四 flag 离关可区分  
4. Score 不出现战斗得分 HUD  
5. LLM 超时可降级且门禁不被绕过  
6. 程序可按 Unity 专章建空壳并挂事件
