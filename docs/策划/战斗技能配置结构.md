# 战斗技能配置结构

> 用途：Unity ScriptableObject / JSON 共用字段规范  
> 对接：`战斗系统.md`、`角色系统_剑客.md`  
> 示例文件：`战斗技能配置_示例.json`

---

## 1. 顶层结构

```json
{
  "version": 1,
  "skills": [ { /* SkillConfig */ }, ... ]
}
```

单条技能 = 一个 `SkillConfig` 对象（也可一对一做成 SO 资产）。

---

## 2. SkillConfig 字段总表

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| skillId | string | ✓ | 唯一 ID，如 `SK_slash` |
| displayName | string | ✓ | UI 名 |
| skillType | enum | ✓ | `BasicAttack` / `ActiveSkill` / `ChargeSkill` / `Passive` |
| shape | enum | ✓ | `meleeBox` / `line` / `sin` / `selfAoE` / `parabola` |
| lockType | enum | ✓ | `none` / `single` |
| unbreakable | bool | ✓ | 单体锁定技：无抵消、不可挡断 → true |
| costs.mp | int | ✓ | MP 消耗；不足不可放 |
| costs.sp | int | ✓ | SP 消耗 |
| costs.gp | int | ✓ | GP 消耗（蓄力槽；0=不耗） |
| cooldown | float | ✓ | 秒；成功释放后进入；**≤0 表示冷却结束可放** |
| chargeTime | float | ✓ | 蓄力秒；`0`=非蓄力；标准蓄力技=`3` |
| allowMoveWhileCast | bool | ✓ | 是否可移动施法 |
| moveRule | enum | ✓ | `sameAsNormal`（与正常释放一致） |
| animation.cast | string | ✓ | 释放动画 ID |
| animation.charge | string | | 蓄力循环动画 |
| animation.recover | string | | 后摇 |
| vfx.cast / projectile / hit | string | | 特效资源 ID |
| sfx.cast / hit | string | | 音效 ID |
| hitbox | object/null | | 近战武器盒；非近战为 null |
| projectile | object/null | | 直线/Sin/抛物线弹道 |
| aoe | object/null | | 范围结算 |
| damage.formulaId | string | ✓ | 伤害公式 ID |
| damage.multiplier | float | ✓ | 倍率 |
| damage.element | string | | 元素/气质标签 |
| damage.canCrit | bool | | |
| ui.icon | string | | |
| ui.showCD | bool | | |
| ui.binding | string | | 输入绑定名：BasicSkill/ChargeSkill/Skill1… |
| tags | string[] | | 检索用 |
| notes | string | | 策划备注 |

## 3. 子结构

### 3.1 hitbox（meleeBox）

| 字段 | 类型 | 说明 |
|------|------|------|
| follow | enum | `weaponBone` / `characterCenter` |
| shape | enum | `obb`（矩形包裹） |
| size | {x,y,z} | 盒尺寸（米） |
| activeFrames | [{start,end}] | 相对施法开始的激活区间（秒） |
| multiHitSameTarget | bool | 同段能否多次伤同一目标 |

### 3.2 projectile（line / sin / parabola）

| 字段 | 类型 | 说明 |
|------|------|------|
| path | enum | `line` / `sin` / `parabola` |
| speed | float | 线/Sin 速度；抛物线可用 lifetime 驱动 |
| length / width | float | 直线有效长度/宽度 |
| pierce | bool | 是否穿透 |
| maxTargets | int | 最大结算人数 |
| sinAmplitude / sinWavelength | float | Sin 专用 |
| parabolaHeight | float | 抛物线弧高 |
| lifeTime | float | 存活秒 |
| impactRadius | float | 抛物线落地爆半径（可再挂 aoe） |

### 3.3 aoe（selfAoE / 落地范围）

| 字段 | 类型 | 说明 |
|------|------|------|
| center | enum | `self` / `target` / `impactPoint` |
| shape | enum | `circle` / `sector` / `box` |
| radius | float | |
| angle | float | 扇形角度；圆用 360 |
| height | float | 竖直厚度 |

### 3.4 damage

| 字段 | 说明 |
|------|------|
| formulaId | 指向数值表公式 |
| multiplier | 技能倍率 |
| element | 可选 |
| canCrit | 是否参与暴击 |

## 4. 枚举速查

```
skillType: BasicAttack | ActiveSkill | ChargeSkill | Passive
shape:     meleeBox | line | sin | selfAoE | parabola
lockType:  none | single
moveRule:  sameAsNormal
```

---

## 5. 释放前检查顺序（程序）

1. skill 存在且已学会  
2. `cooldownRemaining <= 0`  
3. `mp >= costs.mp` 且 `sp >= costs.sp` 且 `gp >= costs.gp`  
4. 若 `chargeTime > 0`：按住满 `chargeTime`（默认 3s）  
5. 若 `lockType == single`：存在有效锁定目标  
6. 通过 → 扣消耗 → 进 CD → 播动画/特效 → 开 hitbox / 生成 projectile / 刷 aoe → 伤害 → 刷新 HP/MP/SP UI  

**MP≤0 或不满足消耗：不能放任何耗魔技能。**  
**SP 不足：不拦技能本身（除非 costs.sp&gt;0）；移动降为仅行走。**

---

## 6. Unity 落地建议

- `SkillConfig` → `ScriptableObject`  
- 运行时：`SkillRuntime { cooldownRemaining, isCharging, chargeElapsed }`  
- 表驱动：JSON 导入 SO，或直接 Addressables 读 JSON  
- 示例见同目录 `战斗技能配置_示例.json`（含斩击 / 天灰无影 / 直线 / Sin / 抛物线）

---

## 7. 验收

1. 任意技能用同一套字段能配置出来  
2. 缺必填字段导入失败并报 skillId  
3. 示例 5 条技能能进运行时检查流水线
