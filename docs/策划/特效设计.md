## 1. VR 规则

| 项 | 约定 |
|----|------|
| 原则 | **世界空间特效优先**；信息用光边/地面预兆，不抢 HMD |
| 禁止 | 全屏白闪、强制相机震动、连续强曝光闪切、贴脸粒子暴喷 |
| 允许 | 短时边缘灰雾、目标描边、地面弧光预警、轻体积雾 |
| UI | 仅允许 **软暗角 vignette**（UI 岗）；不替代受击反馈 |
| 预算（草案） | 同屏战斗粒子系统 ≤ **8** 活跃；单命中 burst ≤ **40** 粒子；Boss 阶段可临时 **12** |
| 可读性 | 敌方危险招式 **预警 ≥0.35s**（与动画/音效同帧）；逃点不靠特效掩盖 |
| 风格 | 冷青影雾、暖烛金边、岩浆橙红；忌赛博霓虹描边 |

## 2. 分类与命名

公式：`VFX_<category>_<name>`（ASCII；中文进 cn_name）

| category | 含义 | 示例 |
|----------|------|------|
| hit | 命中 | `VFX_hit_blade` |
| block | 格挡 | `VFX_block_spark` |
| charge | 蓄力 | `VFX_charge_sword_loop` |
| proj | 弹道 | `VFX_proj_line` / `_sin` / `_parabola` |
| aoe | 范围 | `VFX_aoe_self_ring` |
| status | 状态 | `VFX_status_burn`（预留） |
| spawn | 入场/刷怪 | `VFX_spawn_shadow_drop` |
| death | 死亡 | `VFX_death_ash_green` |
| cutscene | 过场 | `VFX_cs_tailfire_far` |
| env | 环境点缀 | `VFX_env_L03_ember` |

SkillConfig 字段映射：

| SkillConfig | 填 VFX id |
|-------------|-----------|
| `vfx.cast` | 起手/蓄满释放 |
| `vfx.projectile` | 弹道本体 |
| `vfx.hit` | 命中点 |
| （扩展建议）`vfx.telegraph` / `vfx.aoe` | 预警环 / 范围圈；首版可写 notes 或挂 cast |

## 3. Shape → VFX 对照

| shape | cast | projectile | hit / aoe |
|-------|------|------------|-----------|
| meleeBox | 刃光短痕 `VFX_cast_blade` | — | `VFX_hit_blade` |
| line | `VFX_cast_line` | `VFX_proj_line` | `VFX_hit_energy` |
| sin | `VFX_cast_sin` | `VFX_proj_sin` | `VFX_hit_energy` |
| parabola | `VFX_cast_parabola` | `VFX_proj_parabola` | 落地 `VFX_aoe_impact` |
| selfAoE | `VFX_cast_aoe` | — | `VFX_aoe_self_ring` |

玩家示例（对齐示例 JSON）：

| skillId | vfx.cast | vfx.projectile | vfx.hit |
|---------|----------|----------------|---------|
| SK_slash | （可空） | — | `VFX_hit_blade` |
| SK_tianhui_wuying | `VFX_cast_tianhui` | — | `VFX_aoe_self_ring` |
| 直线技 | `VFX_cast_line` | `VFX_proj_line` | `VFX_hit_energy` |
| Sin 技 | `VFX_cast_sin` | `VFX_proj_sin` | `VFX_hit_energy` |
| 抛物技 | `VFX_cast_parabola` | `VFX_proj_parabola` | `VFX_aoe_impact` |

蓄力：`VFX_charge_sword_loop`（3s）→ 满蓄 `VFX_charge_sword_ready` → 释放接 cast。

格挡：`VFX_block_spark`（世界火花，禁全屏闪）。

## 7. 邻岗

| 岗 | 职责 |
|----|------|
| 策划 | 本表、总表 VFX_、与技能/NPC 表交叉引用 |

目录建议：

```
Assets/_Project/VFX/
  Combat/Hit|Block|Charge|Proj|AoE|Unit/
  Cutscene/
  Environment/
```

## 8. 验收

1. 战斗无全屏闪、无强制相机震  
2. 鬼怪雾尾+影拉伸可读；牛头尘冲有侧向逃示意；蛇甩尾/毒涎预警达标  
3. SkillConfig `vfx.*` 均可落到表内 id  
4. L03 飞烬等 env 不遮传送落点  
5. 同屏粒子预算抽测不爆帧（目标机待程序标）
