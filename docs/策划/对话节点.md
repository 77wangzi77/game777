# 对话节点（复杂叙事版）

> 语气：古剑同调，克制。★＝关键句不可跳。谎言选项会改可信度，不立刻失败。

## NPC

| ID | 角色 | 表面身份 | 暗线 |
|----|------|----------|------|
| N_host | 掌柜 | 焦急失主 | 导演假案，保「真简」出驿 |
| N_guest | 旅客 | 怕事过客 | 被雇伪证；可反水 |
| N_mute | 哑仆 | 不会说话 | 旧祠相关；知三抄本规矩 |
| N_self | 旁白 | — | 仅氛围，不剧透 |

## 证据标记（对话条件）

`has_QE1`…`has_QE5`，`trust_mute`，`guest_turned`，`host_suspect`

---

## 掌柜树 N_host

### 开场（QM1）

```
H0 ★「客官……店里昨夜丢了要紧竹简。」
H1 「后院匣被动过。你若侠义，可否一助？」
  → A「我去查」→ 派发 Investigate；host_suspect=0
  → B「先说清楚何时丢的」→ H1b
H1b ★「子时前后。我查房才发现。」→ has_QE1=1
  → C「好，我查」 / D「我自己转转」→ 均进 Investigate
```

### 试探枝（可多次，需已 Investigate）

```
H2 「可有眉目？」
  → 若 has_QE3：「这墨色不像旧物。」→
        H2a（慌）「……许是雨打湿了。」→ host_suspect++
  → 若 has_QE2：「有人说亥时就有响动。」→
        H2b 「旅客听错了。」→ host_suspect++
  → 无证据：「还在查。」→ 结束
```

### 对质 Confront（需矛盾对）

```
HX ★「掌柜，亥时与子时，哪个是真？」
  → 若 host_suspect≥1：HXa「……你知道太多了。」→ 可进 expose 预备
  → 否则：HXb「夜深容易记混。」→ 给弱提示去找哑仆
```

### 抉择回堂 Choice

```
H3 ★「要追贼，还是守匣？」
  → E 追 → flag=chase
  → F 守 → flag=guard
  → G 揭穿（仅 expose 条件满足时显示）★
        「假案是你导的。三份抄本，哪份是真？」
        → H3g 「……留下，我们谈。」→ flag=expose
```

## 旅客树 N_guest

```
G0 「别问我，我什么都没听见。」
  → 请酒 / 出示泥印 → G1
G1 「……亥时，后院有脚步。掌柜让我别说。」→ has_QE2=1
G2（若 has_QE5 或 host_suspect≥1）
  「钱是掌柜给的。简……不在匣里。」→ guest_turned=1
```

## 哑仆线 N_mute（字条 / 木牌，非语音）

| 步骤 | 条件 | 内容 | 产出 |
|------|------|------|------|
| M0 | 进灶房 | 木牌：「水。」 | 可递水 |
| M1 | 递水 | 木牌：「谢。勿告。」 | trust_mute=1 |
| M2 | trust_mute | 字条：「三角。一真二假。」 | has_QE5=1 |
| M3 | trust_mute∧QM2 | 指向钥匙藏处 | 开上房 → 残页 QE3 强化 |

## 旁白

| 时机 | 文本 |
|------|------|
| 入关 | 「月薄。铃响得不是寻常那一声。」 |
| 凑齐矛盾对 | 「两个人，两个时辰——总有一个在演。」 |

| 离关 guard | 「匣是安的。心里那点空，却未安。」 |

## UI / 程序约定

- 选项最多 **3**（仅抉择时；平时 ≤2）
- 证据到手短提示（不弹复杂菜单）；可选「证据回忆」列表只读
- ★ 句不可跳；谎言选项不标颜色（防剧透）
