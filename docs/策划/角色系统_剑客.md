## 9. GP / DP

| 资源 | 全称草案 | 用途 | 上下限 | 回复 |
|------|----------|------|--------|------|
| **GP** | Gauge Point 蓄力槽 | 天灰无影 | 0–100 | 见 §8 |
| **DP** | Defense / Endure Point 霸体耐性（草案） | 抗打断、抵消硬直 | 0–100 | 脱战 5/s；被破招清空 |

**DP 规则草案**

- 斩击中段消耗 DP 0；受击扣 DP = 伤害折算  
- DP&gt;0：轻硬直可减；DP=0：下一次受击强制大硬直  
- 天灰无影释放瞬间：获得短时 DP 盾 40（可选）  
- **若你心中 GP/DP 是别的含义，直接改本表**
