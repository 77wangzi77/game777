# VRgame · UI 界面清单（首版 / Vertical Slice）

> 对齐玩法一页纸：对话探索 → 轻节点 → 过场/选择  
> 目标：支撑 3–5 分钟可戴头显走完的切片

## P0（切片必有）

| ID | 界面 | 说明 | 状态 |
|----|------|------|------|
| UI-01 | 启动/主菜单 | 开始、继续、设置、退出；坐姿可读 | 待出视觉 |
| UI-02 | 对话框 | 角色名+正文+继续；世界锚 | 待出视觉 |
| UI-03 | 分支选项 | 2–3 项；手柄射线可选 | 待出视觉 |
| UI-04 | 交互提示 | 「扳机互动」类短提示 | 待出视觉 |
| UI-05 | 暂停/设置 | 含舒适度项入口 | 待出视觉 |
| UI-06 | 任务短标 | 一句话目标，可收起 | 待出视觉 |
