# 封闭关卡 · 四层连通

> 修订：2026-11-03 · 关卡概念

## 层序（下→上）

| 层 | 主题 | 空间 | 通往上层 |
|----|------|------|----------|
| L1 | 高山洞窟 | 亭台、崖径、洞口 | 中央石阶 → 天窗/升层口 |
| L2 | 石桥厅 | 封闭峡谷内石桥、牌楼、门楼 | 门楼内楼梯/竖井 → L3 |
| L3 | 岩浆窟 | 平台、链桥、封印门 | 封印门后竖井 → L4 |
| L4 | 洞府殿 | 祭坛、云龙柱、圆雕壁 | 终局/出口（可回落存档点） |

## 玩家流向

入关 L1 → 升 L2 过桥 → 降/穿至 L3 闯岩浆 → 升 L4 洞府揭晓。

外壳全程封闭；层间仅楼梯、竖井、封印门连通。
