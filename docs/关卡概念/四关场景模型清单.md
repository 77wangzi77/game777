## 制作优先级建议（首轮）

每关先做 **P0 环境块 + 1 主建筑 + 关键道具**，能搭通封闭流线再补 P1/P2。

| 关 | 首轮必做 |
|----|----------|
| 高山 | CaveMouth + CliffPath + Pavilion + Pine + Teleport |
| 石桥 | BridgeDeck + Paifang + FarGatehouse + LionRail + OilLamp |
| 岩浆 | CavernShell + Platforms + LavaRiver + SealGate + Brazier |
| 洞府 | HallShell + Pillars + Relief + Altar + BambooSlips |
