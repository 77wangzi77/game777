# L01《残简三声》关卡概念说明

> 岗位：关卡概念设计 · 汇报 → VRgame·制作统筹  
> 对齐：`docs/策划/剧情关卡结构_VS.md` · `任务流.md` · `对话节点.md` · `docs/场景与资产规范.md`  
> 假设（待拍板前）：**原创同调**气质；**极少战斗、服务叙事**；主氛围 **月下驿站 + 竹林口**  
> 修订：2026-11-02

## 1. 一句话

月夜驿站是「假案剧场」：玩家用身体走动对照谎言，在子时前用证据改写自己在这场戏里的位置。

## 2. 空间叙事意图

| 意图 | 做法 |
|------|------|
| 今夜不对 | 入关风铃音色异常 + 外廊更鼓可闻；堂内灯火偏暖、后院偏冷 |
| 信息差可走通 | 三人口径分布在三个可回跳空间；证据物分散，逼玩家建立「证据板思维」 |
| 复杂可感 | 第三条结局（揭穿）必须靠空间探索凑齐，不能只站着听完对话 |
| VR 舒适 | 块与块门洞清晰；关键互动 0.9–1.4 m；传送落点可见；无强制高速旋转 |

主题锚点（与主线大纲一致）：**竹简 = 可被替换的记忆**。本关只让玩家感到「有人在改今夜的说法」，不摊牌旧祠世界观。

## 3. 玩法节点总图（空间 × 动作 × 叙事）

| 节点 | 空间块 | 玩家动作 | 剧情功能 | 时长 | 任务锚 |
|------|--------|----------|----------|------|--------|
| N1 入关 | ENV_L01_Porch 外廊 | 传送落点 → 听风铃/旁白 → 进堂 | 建立不安 | ~2′ | QM0 |
| N2 假案 | ENV_L01_Hall 堂内·掌柜锚 | 主对话（可试探） | 立假案 | ~3′ | QM1 |
| N3 闲话 | 堂内·旅客锚 | 闲话 / 请酒 / 出示泥印 | 撕开时间矛盾 | ~2′ | QE2 / QC_g |
| N4 搜证 | 侧廊 + 客房 + 后院 | 检视 5 线索（3真1伪1红鲱鱼） | 证据板 | ~5′ | QE3/QE4 |
| N5 暗线 | 灶房柴间 | 递水、字条、钥匙指向 | 身份/规则层 | ~2′ | QE5 / QC_m |
| N6 对质 | 堂内可回跳 | 用矛盾证据开对质枝 | 信息闭合 | ~3′ | QM3 |
| N7 抉择 | 堂 / 外廊 | chase / guard / expose | 站队 flag | ~2′ | QM4 |

## 4. 区块概念（给场景岗拆任务）

### 4.1 外廊 `ENV_L01_Porch`

- **感觉**：石阶、窄廊、月薄；暖烛在门内，冷月在廊外。
- **引导**：门洞光 spill + 风铃；更鼓声源在远处（时限 UI 可叠）。
- **锚点**：`Anchor_Teleport` 入场；`Anchor_Look` 朝堂门；可选 `Trigger_Bell`。
- **禁区**：廊外虚空不做可走；护栏防坠落焦虑。

### 4.2 堂内 `ENV_L01_Hall`

- **感觉**：假案舞台。掌柜与旅客分两侧，中间可站立对话圈，避免背对背死角。
- **双锚**：`NPC_Host`、`NPC_Guest` 各带对话触发半径；对质时焦点光可短暂压旅客侧。
- **舒适**：对话可坐姿完成；选项面板世界空间或腕表式，不挡主要视线。

### 4.3 客房侧廊 `ENV_L01_Wing`

- **感觉**：私密、压抑；线索 1–2（如泥印、残页碎片）半遮挡，鼓励走近。
- **净宽** ≥ 1.2 m；死角必有回头路径。

### 4.4 上房 `ENV_L01_Upper`（可锁）

- **感觉**：「不该进」；锁态可见，开锁后残页（QE3）在案几眼平高度。
- **钥匙**：来自哑仆线，不放在显眼宝箱。

### 4.5 后院 `ENV_L01_Yard`

- **感觉**：伪匣是「给人发现的」；月光硬、人气少。
- **解谜**：匣锁反装（QE4）——交互一次可读文案打架即可，不做多步机关链。
- **红鲱鱼 / 伪线索**：与真线索同视觉权重，靠文案矛盾揭露。

### 4.6 灶房柴间 `ENV_L01_Kitchen`

- **感觉**：热、暗、人间烟火；与堂内「演戏」对照。
- **交互**：木牌 / 字条近距检视；递水为信任门槛，不做语音对话。

### 4.7 竹林入口 `ENV_L01_Bamboo`

- **感觉**：离关边界；竹影剪影，过场按 `chapter1_flag` 四值换旁白与镜头朝向。
- **制作范围**：边界壳 + 四种短过场钩即可；竹林纵深章 2 再扩。

## 5. 线索物摆放原则（对接任务流 QE）

| 线索 | 建议位置 | 玩家读法 |
|------|----------|----------|
| QE1 掌柜时间 | 对话自动 | 无空间物 |
| QE2 旅客时间 | 堂内深谈 | 无空间物 |
| QE3 残页墨未干 | 上房（或客房强化） | 检视文案 vs「旧藏」 |
| QE4 匣锁反装 | 后院 | 解谜成功文案 |
| QE5 字条 | 灶房 | 信任后出现 |
| 伪物 / 红鲱鱼 | 侧廊或客房 | 文案与他证打架 |

**揭穿路径空间要求**：玩家必须至少离开堂内一次（后院或上房）+ 进灶房，才能逻辑上凑齐 expose 条件——保证「复杂」靠走动达成。

## 6. 轻战斗 / 对峙（默认极少）

首版 **不做** 数值战斗。若拍板仍「服务叙事」：至多在抉择后 `expose` 枝加 **1 次威慑性对峙演出**（站桩、亮刃、对话结束），无连招、无血条。  
若改为「关卡战斗为主」：本概念需重做节点密度与安全区——**先问用户再改**。
