# 无悔之剑 · UI 拆分格式

## A. 游戏 Icon（独立资产）

| ID | 用途 | 形态 | 导出建议 |
|----|------|------|----------|
| ICO-01 | 进入游戏 | 横剑 | PNG 透明底 256 / 512 |
| ICO-02 | 保存 | 横剑 + 卷轴 | 同上 |
| ICO-03 | 选项 | 横剑 + 机关 | 同上 |
| ICO-04 | 退出游戏 | 横剑（断锋感） | 同上 |
| ICO-05 | 主标识 | 牛头骨 + 角（可叠十字/锚意象） | 512 / 1024 |
| ICO-06 | 应用/商店图标 | 由 ICO-05 裁方 | 1024 方图 |

存放：`资料/icons/`

## B. UI 界面格式（主菜单）

| 层 | 内容 | 锚定 | 备注 |
|----|------|------|------|
| BG | 昏暗鬼影背景 | 全屏/天空盒或平面 | 可换图 |
| Frame | 金色外框面板 | 世界锚 ~1.5 m | 竖向菜单盒 |
| Title | 「无悔之剑」+ 副标 | 面板上方或屏幕左上 | 圆滑张力字 |
| List | 四键竖排 | 面板内 | 进入游戏 / 保存 / 选项 / 退出游戏 |
| Crest | ICO-05 | 右下或面板角 | 牛头人气质 |
| FX | 点击血光流动 | 仅选中键 | 金亮 + 血红扫光 |

### 按钮状态

| 状态 | 视觉 |
|------|------|
| 常态 | 银灰字、弱描边 |
| 悬停 | 金边微亮 |
| 点击 | 金橙框 + 血光移动 |
| 禁用 | 降饱和、不可点 |

### 进入游戏后

确认 YES/NO → YES 加载图进场景 / NO 退出（已定逻辑）

## C. 命名约定

`UI_Main_*.png` 整屏概念 · `ICO_*.png` 单图标 · `FX_BtnBlood_*.png` 特效参考
