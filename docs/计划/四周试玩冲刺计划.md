> 协作：程序（+Cursor 云代理）· 策划 · VR场景 · UI美术 · 数值 · 关卡概念  
> 用户硬要求：一个月完成；所有工作必须详细；已向各岗发确认  
> 资源规则：`docs/资源/命名规范.md`；只引用总表 locked（拍板前 draft）

## 4. 每日工作规范（程序）

1. 产出必须可检查（进仓或写清路径）  
2. 事件名/DLG_ 与策划表、资源总表一致；改名走 redirects+changelog  
3. 提交说明中文短句带模块标签  
4. 禁止 API Key 明文  
5. 重大改派先问用户  
6. Cursor 云代理：本岗出任务书与验收，代理写码，本岗判定
