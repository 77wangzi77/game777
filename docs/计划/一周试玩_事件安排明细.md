> 关卡：`LV_01_inn`《残简三声》驿站七块灰模（四层关后置）  
> 引擎：Unity · OpenXR/XRI · EventBus  
> 资源：总表 draft；用户拍板前不升 locked；对话 id 用 `DLG_*`（旧 `N_guest/host/mute` 见 `redirects.csv`）  
> 字数：主句≤48 · 选项≤16×≤3  
> Done：传送 → QM0→QM5 → 三分支+none → 存档；expose 路径可跑；**不做**精模/完整战斗/LLM 实装  
> 修订：2026-11-03（Asia/Shanghai）· 对齐任务流 / 对话节点 / UI接口 / 各岗日表；§3 驿站 ENV_Inn_* 命名锁

## 1. 状态机（程序唯一主轴）

```
Boot → Arrive → CaseBrief → Investigate{Explore|Talk|Puzzle}
      → Confront? → Choice → Outro(flag) → Save
```

| Mode | 对应节拍 | 进入事件 | 退出条件 |
|------|----------|----------|----------|
| Arrival | N1 外廊 | `Arrive`（入场传送完成） | 进堂内交互圈 → QM0 完成 |
| CaseBrief | N2 假案 | `Dialogue.NodeReached`（掌柜开场） | QM1 完成（竹简失踪句）→ `Quest.Advanced(QM1)` |
| Investigate | N3–N5 | `Quest.Advanced(QM1)` | QM2 达标后可进 Confront；或更鼓强制 Choice |
| Confront | N6 | 玩家开对质 | 走完对质 / 取消回 Investigate |
| Choice | N7 | `Level.WatchDrum` 时限到 **或** 玩家主动 | 选定 chase/guard/expose **或** 超时 none |
| Outro | N8 | `Level.Outro` | 过场完 → Save |

硬规则：

1. Investigate 内：堂 ↔ 侧廊 ↔ 后院 ↔ 灶房 **自由回跳**  
2. 更鼓到点 **强制** Choice；前可留 **30s** 最后对质窗（`SV_last_confront_window`）  
3. Confront **可跳过**；跳过则 **锁死 expose**  
4. expose 选项仅当：`(QE1∧QE2) ∧ (QE3∨QE4) ∧ QE5 ∧ confront_done ∧ ¬confront_skipped`

## 2. EventBus 目录（谁发 / 谁订 / 载荷）

| 事件名 | 谁 Publish | 谁 Subscribe | 载荷（最小） | 玩家可感 |
|--------|------------|--------------|--------------|----------|
| `Arrive` | LevelGate / 传送落点 | UI 短标；NarrativeRuntime；Quest | `zoneId`（ENV_*） | 任务短标刷新；可选「已到达」≤1.5s |
| `Anomaly.Bell` | 风铃 InteractableUse | UI hint；Narrative（SV_bell） | 无 / 可选方向 | 入关不安；弱方向标 |
| `Dialogue.NodeReached` | DialogueTrigger | UI 对话框；Narrative；Quest | `dlgId`, `nodeId` | 开对话+选项 |
| `Dialogue.ChoicePicked` | UI 选项确认 | Narrative；Quest；Save flags | `dlgId`, `choiceId` | 进下一节点 / 改 flag |
| `Item.Inspected` | 线索 InteractableUse | UI 检视框；Quest（QE*） | `propId`, `qeId?` | 证据短提示 |
| `Npc.MuteTrust` | 哑仆递水/字条逻辑 | UI；Quest（QE5/钥匙） | `trust_mute` int | 信任短提示 |
| `Quest.Advanced` | QuestService | UI 短标；Narrative Mode | `from`, `to`（QM*） | 任务一句更新 |
| `Evidence.Gained` | QuestService | UI 证据栏；Narrative SV | `qeId` | 短提示入手 |
| `Level.WatchDrum` | WatchDrumTimer | UI 时辰/标题；Mode→Choice | `phase`: warn\|force | 更鼓加压；30s 窗 |
| `Level.Outro` | OutroTrigger（竹林口） | UI 结算；SaveService | `flag` | 黑场+ST 旁白 |
| `Save.Requested` / `Save.Done` | 菜单/自动 | UI「已保存」 | slot | 非阻断提示 |
| `Combat.SkipAvailable` | 程序读 CFG 后 | UI 可跳过按钮（若有） | — | 本周可整段跳过战斗 |
| `Threat.Resolve` | 程序威慑结算 | UI/对话文案 key | success bool | 唬退成功/失败占位 |
| `Numeric.TablesReady` | 数值岗 | 程序 Import | path+schema | 不进玩家视野 |

菜单（非叙事总线也可）：开主菜单四键 · YES/NO 进游戏 · 选项舒适度（字号/距离/利手/坐姿）。

## 4. 主线任务事件链（QM0→QM5）

| 步骤 | 触发 | 完成条件 | 发出事件 | 解锁 |
|------|------|----------|----------|------|
| **QM0 落脚** | 入关 `Arrive(Porch)` | 进入堂内交互圈 | `Quest.Advanced(QM0→QM1)` | 可开掌柜对话 |
| **QM1 听假案** | 掌柜 `DLG_01_host` 开场 | 走到「竹简失踪」★节点 | `Quest.Advanced(→QM2)`；SV_case_erected | QE*/QC*；Mode→Investigate |
| **QM2 查今夜** | Investigate 自由 | 证据点≥3 **或** 人物深谈≥2 | `Quest.Advanced(→QM3可)`；SV_qm2_ready | 可开对质 |
| **QM3 对质** | 玩家开对质（需矛盾对 QE1∧QE2） | 走完一次对质对话 | `Quest.Advanced`；SV_confront_done | 判定 expose 门 |
| **QM4 子时抉择** | 更鼓 force **或** 主动 | 选 chase/guard/expose；超时→none | `Dialogue.ChoicePicked` → 写 flag | Mode→Outro |
| **QM5 夜奔** | 到竹林口 | `Level.Outro(flag)` 播完 | Save | 试玩通关 |

### 证据 / 人物线事件

| id | 获得事件 | 条件 | 写入 |
|----|----------|------|------|
| QE1 | 掌柜 H1b 对话 | CaseBrief | `has_QE1` · `Evidence.Gained` |
| QE2 | 旅客深谈（请酒/泥印） | Investigate | `has_QE2` |
| QE3 | 上房残页 `Item.Inspected` | 钥匙（哑仆线）或客房强化 | `has_QE3` |

## 7. 试玩验收事件勾选（D7）

1. 传送进外廊 → 收到 `Arrive` → 短标可见  
2. 风铃或旁白 → `Anomaly.Bell` / 入关旁白至少其一  
3. 掌柜对话走完 QM1 → Mode 进入 Investigate  
4. 至少入手 3 证据点 **或** 2 条人物深谈 → QM2  
5. （可选）对质一次 → 未跳过则可看见 expose 门控正确  
6. 更鼓或主动进 Choice → 三选项；无 expose 条件时第三条不出现  
7. 四 flag 各能进竹林口 → `Level.Outro` 旁白可区分  
8. 存档可读 flag；读档后 Mode/任务短标不炸  
9. 战斗：可跳过或唬退占位，**不挡**主线
