## 界面（图片 / 动态图）

| ID | 元素 | 类型 | 说明 |
|----|------|------|------|
| CBT-UI-01 | 生命条 | 图片+动态 | 边缘弱存在；掉血用暗红闪（动态） |
| CBT-UI-02 | 体力/气力条 | 图片 | 与生命条并列，勿挡中心 |
| CBT-UI-03 | 技能栏 | ICON 槽 | 横剑同系小标；冷却用动态 ICON |
| CBT-UI-04 | 锁定框 | ICON/动态 ICON | 准星式锁定，少遮挡 |
| CBT-UI-05 | 受击/暴击反馈 | 动态图/动态 ICON | 短血光，禁高频闪 |
| CBT-UI-06 | 敌人名牌 | 图片 | 世界锚头顶，字少 |

舒适度：中心视野尽量空；跟头 UI 仅短提示。
