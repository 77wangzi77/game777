# VRgame · UI 舒适度与视觉规范（首版草案）

> 岗位：UI美术 · 汇报 → 制作统筹  
> 范围：PCVR · Unity · 古剑奇谭气质剧情关卡  
> 状态：草案，可随玩法一页纸细化修订

## 1. 设计目标

- 仙侠叙事可读、不抢场景；HUD 极简，对话与提示优先。
- 晕动友好：少遮挡、少强制注视、少屏幕大幅运动。
- 坐姿/站姿均可完成主菜单、对话、选项。

## 2. 舒适度硬约束（PCVR）

| 项 | 约定 |
|----|------|
| 锚定 | 世界空间 UI 优先固定在场景锚点；跟头 UI 仅短提示 |
| 距离 | 可交互面板约 1.2–1.8 m；字号保证 1.5 m 可读 |
| 视角 | 主内容落在水平 ±20°、俯仰 0°～-15°；避免仰视长读 |
| 运动 | 禁止 UI 随头部高速拖影；淡入淡出 ≤0.3 s；无强制旋转过场 UI |
| 透明度 | 半透明底板；边缘柔化；不挡关键路径与交互点 |
| 闪烁 | 禁用高频闪；危险/失败用色相+图标，不用强闪 |
| 对比 | 正文对比度足够；避免纯白满屏；暗场用暖金/青灰描边提字 |

## 3. 视觉气质（古剑向）

- 色板草案：墨青底、暖金描边、月白正文、朱红强调（选项/关键道具）。
- 材质感：宣纸/绢纹轻噪声、细金线框；少用厚重科幻玻璃。
- 字体：标题可略书法感；正文必须高可读无衬线或轻度衬线；VR 下忌细笔画。
- 装饰：角花/云纹仅角落；不环绕正文。

## 4. 界面分层

| 层 | 用途 | 锚定 | 示例 |
|----|------|------|------|
| A 沉浸提示 | 短时、少字 | 跟头或世界短暂 | 「可拾取」「看向以互动」 |
| B 对话/选项 | 剧情主读 | 世界锚 / 角色旁 | 对话框、分支选项 |
| C 系统菜单 | 设置/存读/退出 | 世界固定面板 | 暂停、舒适度选项 |
| D HUD | 常驻极简 | 边缘弱存在或按需 | 任务短标、准星/射线反馈 |

首版默认：**无血条常驻**；战斗若有，用短时状态条+受击反馈，不作大面积 HUD。

## 5. 输入与反馈（配合手柄）

- 射线指向 + 扳机确认；悬停高亮描边（金），按下微缩反馈。
- 选项热区 ≥ 按钮视觉；间距防误触。
- 所有可点控件提供：悬停音轻、确认音、不可用灰态。
- 取消/返回固定在习惯侧，文案明确。

## 6. 舒适度菜单（必做项）

设置内需可调（程序实现，本岗出视觉与文案位）：

- 移动模式提示文案位（传送 / 滑步）
- 晕动减缓：视野渐晕强度、转动平滑
- UI 缩放、对话字号
- 坐姿模式：面板高度预设

## 7. 不做（首版）

- 复杂小地图常驻、准星射击式 HUD
- 屏幕空间满屏字幕墙
- 强制头部锁定长文本
