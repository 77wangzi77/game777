# 无悔之剑 · UI 资产分类（强制区分）

| 类型 | 英文标签 | 用途 | 目录 | 命名 | 格式建议 |
|------|----------|------|------|------|----------|
| **ICON** | `ICON` | 静止小图标（按钮旁、角标） | `资料/icons/` | `ICO_功能_状态.png` | PNG 透明；256/512 |
| **图片** | `IMG` | 静止大图（背景、加载图、面板底） | `资料/images/` | `IMG_界面_内容.png` | PNG/JPG；概念或最终 |
| **动态图** | `ANIM_IMG` | 整屏/大块循环动效（鬼影雾、加载循环） | `资料/anim_images/` | `ANIM_IMG_场景_效果.webp/mp4` | WebP/APNG/短视频 |
| **动态 ICON** | `ANIM_ICO` | 图标级动效（血光扫过、悬停闪） | `资料/anim_icons/` | `ANIM_ICO_功能_效果.webp` | WebP/序列帧 PNG |

## 禁止混用

- 整屏概念图 ≠ ICON（归 **图片**）
- 按钮旁静止剑标 = **ICON**；带血光扫过的同键 = **动态 ICON**
- 背景鬼影循环 = **动态图**；单帧背景静图 = **图片**

## 主菜单对应

| 元素 | 类型 |
|------|------|
| 横剑四键标 | ICON |
| 牛头纹章静帧 | ICON |
| 主界面整屏静帧 | 图片 |
| 加载场景图 | 图片 |
| 背景鬼影雾循环 | 动态图 |
| 点击血光扫过 | 动态 ICON |

## 状态机（ICON → 动态 ICON）

常态/禁用用 **ICON**；悬停、点击用 **动态 ICON** 叠加或替换。
