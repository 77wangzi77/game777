# 玩法一页纸（复杂叙事版）

## 一句话

**古剑奇谭风格剧情关卡**——PCVR 下以关卡推进**高信息密度**仙侠叙事：假案、矛盾证据、人物反水与分支后果。

## 核心循环

1. 入关 → 多方对话（口径不一）
2. 探索线索 / 轻解谜 → 证据板思维
3. 对质（可选）→ 站队选择 → 过场钩子进下一关

## 会话与舒适度

- 单关目标：15–25 分钟可断点（复杂版略长于初稿）
- 移动：传送 + 有限滑步
- 舒适度：无强制高速旋转；过场可坐姿

## 平台

- PCVR · Unity；最低头显/GPU 档位待补

## 非目标

- 开放世界、联机 MMO
- 以战斗手感为主的动作关（除非用户改拍板）

## 已确认 / 待拍板

- 已确认：剧情要复杂（2026-11-02）
- 待拍板：原创同调 vs 对标某部；战斗比重
