# 场景与资产规范（首版草案）

> 岗位：VR场景制作 · 汇报 → 制作统筹  
> 范围：PCVR · Unity · 古剑奇谭气质剧情关卡  
> 状态：草案，重大项待用户拍板后升正式版

## 1. 目标

让首版 vertical slice 的场景可搭、可进工程、可戴上头显走通，且晕动友好、风格统一。

## 2. 尺度与舒适度（PCVR）

| 项 | 约定（草案） |
|----|--------------|
| 世界单位 | 1 unit = 1 米 |
| 玩家眼高参考 | 约 1.6–1.7 m（坐/站均可；过场支持坐姿） |
| 移动 | 传送为主 + 有限滑步；禁止强制高速旋转 |
| 通道最小净宽 | ≥ 1.2 m（手柄/碰撞友好） |
| 关键高度 | 重点互动点 0.9–1.4 m 眼平附近 |
| 传送落点 | 平坦、无障碍、落点半径清晰可见 |

## 3. 空间流线（关卡块）

单关按「块」组装，首版不做无缝大地图。

推荐块类型：

1. **入场区**：安全落点 + 朝向锚点 + 轻引导（光/音/路）
2. **探索区**：可环视、可走近互动物（道具/机关/对话触发）
3. **叙事节点**：对话或过场触发区（可坐姿完成）
4. **解谜/轻战斗节点**：边界清晰，失败可回落点
5. **出口/转场**：明确去向下一块或下一关

流线原则：一眼能懂下一步；死角要有回头路径；关键路径上避免强眩晕刺激。

## 4. 灯光与氛围（古剑气质 · 已锁定四层）

用户确认（2026-11-03）：场景制作范围 = 关卡概念 **四层封闭关**（高山→石桥→岩浆→洞府）。明细见 `docs/场景/四层空间流线与灯光制作清单.md` 与 `docs/关卡概念/四层明暗关系.md`。

| 层 | Key | Fill | Accent | 色温节奏 |
|----|-----|------|--------|----------|
| L1 高山 | 天窗冷光自上而下 | 弱环境青灰 | 洞口火把暖点 | 上亮下暗 |
| L2 石桥 | 高窗冷光斜切桥面 | 雾反射微亮 | 栏杆灯笼暖点 | 冷长光斑 + 暖引导 |
| L3 岩浆 | **底光**岩浆上照 | 几乎无天空光 | 火盆高亮 | 下亮上暗，高饱和暖 |
| L4 洞府 | 祭坛暖顶光/灯火 | 柱侧弱反射 | 烛火局部 | 中心亮四角沉，中饱和暖 |

通用：忌赛博霓虹；轻体积雾；过场可短压暗，避免连续闪切。Blockout 只用灰阶 + 光源色。

## 5. 资产与命名（Unity）

### 5.1 目录（工程落地后）

```
Assets/VRgame/
  Scenes/
  Environments/     # 模块化场景块 Prefab
  Props/
  Lighting/         # 灯光预设 / Sky / Volume
  Materials/
  Textures/
  Colliders/
```

### 5.2 命名

- 场景块：`ENV_<关卡>_<块名>`，如 `ENV_L01_Entrance`
- 道具：`PROP_<类别>_<名>`
- 灯光预设：`LIT_<氛围名>`
- 材质：`M_<表面>_<变体>`
- 避免中文文件名进工程；中文说明放 Markdown

### 5.3 模块化

- 块与块用统一对接边（门口/桥面/平台对齐）
- Prefab 自带碰撞与传送锚点空物体：`AN_Teleport`、`AN_Look`
- 高模/装饰与碰撞网格分离，碰撞尽量用简单凸包/盒

## 6. 首版 Vertical Slice（场景侧验收草案）

戴上头显 3–5 分钟可走完：

1. 传送入场 → 朝向正确
2. 沿引导光/路走到叙事点（可触发占位对话）
3. 完成 1 个轻互动（拾取或机关）
4. 到达出口锚点

场景侧交付物：1 个主场景 Scene + 1 套氛围灯光 + 模块 Prefab 清单 + 已知问题（穿模/晕动点）。
