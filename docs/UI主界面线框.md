# VRgame · 主界面线框（UI-01）

> 风格：古剑奇谭 UI · 墨青底 / 暖金描边 / 月白正文  
> 布局：竖排四键，世界锚面板，坐姿可读

## 线框（示意）

```
┌─────────────────────────────────────┐
│           【游戏标题 / Logo】         │
│                                     │
│         ┌─────────────────┐         │
│         │   进 入 游 戏    │         │
│         └─────────────────┘         │
│         ┌─────────────────┐         │
│         │      保 存      │         │
│         └─────────────────┘         │
│         ┌─────────────────┐         │
│         │      选 项      │         │
│         └─────────────────┘         │
│         ┌─────────────────┐         │
│         │    游 戏 退 出   │         │
│         └─────────────────┘         │
│                                     │
│         （角花 · 细金线框）           │
└─────────────────────────────────────┘
```

## 尺寸与交互（草案）

| 项 | 约定 |
|----|------|
| 面板距离 | 约 1.5 m |
| 按钮高 | 可射线点中；间距防误触 |
| 悬停 | 暖金描边加亮 |
| 确认 | 扳机；进入游戏后再弹 YES/NO |

## 进入游戏确认框

```
┌──────────────────┐
│  是否进入游戏？   │
│  [ YES ] [ NO ]  │
└──────────────────┘
```

YES → 加载图 → 场景；NO → 退出（按已定逻辑）
