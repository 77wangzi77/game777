## 1. 总线（AudioMixer）

| Bus | 用途 | 默认建议 |
|-----|------|----------|
| Master | 总音量 | 0 dB |
| BGM | 探索/战斗/过场/刺音 | −6 |
| SFX_Combat | 武器/命中/预警/技能 | −3 |
| SFX_UI | 菜单/HUD | −4 |
| SFX_World | 门/拾取/传送/脚步 | −5 |
| VO | 旁白/点名/短句 | −2（优先 duck） |
| Amb | 层氛围床 | −8；战斗再 −4〜−6 |

Snapshot：`Snap_Explore` / `Snap_Combat` / `Snap_Boss` / `Snap_Cutscene` / `Snap_Result`。

## 2. 如何用 CSV

1. **id** 与 Addressables 资源同名（升 locked 后）。  
2. **type**：BGM / SND / VO / AMB（氛围床文件仍用 `SND_amb_*` 前缀，Mixer 走 Amb）。  
3. **bus** 决定挂接子混音；**spatial**：BGM/VO/UI/Amb=2d，战斗与世界 SFX=3d。  
4. **trigger_event** 对齐程序 EventBus / AudioDirector（如 `Combat.Start.*`、`BI_serpent`）。  
5. **priority** 数字越小越优先保活（预警=1）。  
6. **path_placeholder** 为工程相对路径占位；音频文件未到齐前勿改 id。  
7. 探索↔战斗 crossfade **1.5–2.5s**；Boss intro 与 Timeline 对齐后进 loop。

## 3. 本表规模

共 **56** 行（含设计文档种子 + 扩展：`SND_foot_dirt`/`SND_door_wood`/`SND_box_open`、VO 短句/蛇点名、UI 三声）。

### 分组计数

- AMB: 5
- BGM: 15
- SND: 32
- VO: 4

## 4. 验收要点

1. 无突然贴耳大音；战斗相对探索 ≤+6dB。  
2. 鬼怪扑杀 / 牛头抬腿 / 蛇甩尾 **预警音可读**。  
3. VO 出时 BGM duck；字幕可关 VO。  
4. 同 clip 短时叠消 ≤3 层。
