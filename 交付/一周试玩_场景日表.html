D1（日1）· 开建外廊+堂

事件 / 产出

1. 新建 Blender 工程：`VRgame_blender/blockout/LV_01_inn_Blockout.blend`（与四层文件分开）

2. 建 Collection：`ENV_01_porch` / `ENV_01_hall` / `Anchors` / `Colliders`

3. 灰盒：外廊石阶+窄廊+堂门洞；堂内地面+双侧 NPC 站位台（无角色模）

4. 埋点：`AN_Teleport_01_porch_spawn`、`AN_Look_01_hall_door`、`AN_Teleport_01_hall_center`

5. 总表追加上述 ENV/AN 行，owner=场景，status=draft

验收：Blender 里从 spawn 视线能看进堂门；单位 1m；通道净宽≥1.2m

依赖：无

交谁：自检；路径告知程序

D2（日2）· 七区壳 + UI 锚

事件 / 产出

1. 补齐 `wing` / `upper` / `yard` / `kitchen` / `bamboo` 灰盒外壳与门洞连通

2. 每区 ≥1 个 `AN_Teleport_*`；关键朝向 `AN_Look_*`

3. 埋 UI 锚：`AN_Look_UI_dialogue`（堂内主对话位）、`AN_Look_UI_menu`（外廊或暂停安全位）、`AN_Look_UI_choice`（抉择位，堂/外廊）

4. 上房门：锁态可见盒子（`PROP_01_upper_lock` 占位）

验收：七 Collection 齐；传送空物体命名可读；UI 三锚坐标写下表（世界坐标一页）

依赖：UI 确认锚大致朝向；不阻塞可先按堂内眼平 1.5m

交谁：@UI 美术坐标；@程序 预留挂点

D3（日3）· 碰撞 + FBX 首包

事件 / 产出

1. 每区 `PROP_ColliderProxy` 盒：可走地面、护栏、不可坠虚空

2. 门洞净空检查（碰头高≥2.0m）

3. 导出 FBX：`VRgame_blender/export/LV_01_inn_blockout_D3.fbx`（Scale 1，含空物体）

4. 导出说明 md：轴向、单位、AN 列表

验收：程序能导入；踩传送点名与空物体一致；无必备精模

依赖：程序工程可进资产（或先放 `blender/export` 等仓）

交谁：@Unity程序

D4（日4）· 灯光包 + 落点抛光

事件 / 产出

1. 灯光预设（Blender 参考灯 + 说明给 Unity Volume）：

- `LIT_01_porch_cold` 廊外冷月

- `LIT_01_hall_warm` 堂内暖烛

- 后院偏冷、灶房偏暖短注

2. 传送落点加可见圆盘灰模 `PROP_TeleportPad`（复用）

3. 修 D3 反馈的穿模/卡缝

验收：廊/堂色温可区分；落点半径在头显/模拟器里可读

依赖：程序已挂基础 XR 传送更佳；否则先自测视角

交谁：@程序

D5（日5）· 线索/风铃/灶房占位

事件 / 产出

1. PROP 灰盒占位（眼平 0.9–1.4m）：

- `PROP_01_wind_chime`（外廊）

- `PROP_01_clue_scrap`（上房残页）

- `PROP_01_box_fake`（后院匣）

- `PROP_01_note_kitchen`（灶房字条）

- 红鲱鱼/伪物各 1：`PROP_01_clue_redherring`

2. 竹林口：边界壳 + `AN_Teleport_01_bamboo_exit`（离关）

3. 按策划 D5「触发区清单」把 `AN_Trigger_*` 空物体对齐改名（若清单迟到：先占位名+对照表）

验收：expose 路径空间上必须离开堂→后院或上房→灶房 可走通

依赖：策划触发区清单（D5）；没有则用概念说明 §5 默认位

交谁：@策划 @程序；更新总表 draft

D6（日6）· 触发对齐 + expose 复跑
